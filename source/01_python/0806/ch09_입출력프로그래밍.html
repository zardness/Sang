1파일에 데이터 저장하고 불러오기

지금까지 만든 프로그램은 종료하면 변수의 데이터가 모두 사라졌어요. 파일에 저장해 두면 다음 실행 때 다시 불러올 수 있습니다. 그 출발점이 open() 함수예요.

📂 open() — 파일 열기
file_pointer = open(파일이름, 모드, encoding='...') — 파일을 열고 파일 객체를 돌려줘요. 이 객체의 write()로 쓰고 readline()/readlines()로 읽습니다.
🚪 비유 — 창고 문을 여는 것과 같아요. 문을 열 때 "읽으러 왔어요(r)" / "새로 채우러 왔어요(w)" / "덧붙이러 왔어요(a)"라고 목적(모드)을 말해야 하고, 볼일이 끝나면 문을 꼭 닫아야(close()) 합니다.
모드이름동작
r읽기 모드파일을 읽기만 할 때 (기본값)
w쓰기 모드파일에 새로 쓸 때 — 기존 내용은 지워짐!
a추가 모드파일의 맨 끝에 덧붙일 때
b바이너리 모드피클 등 이진 데이터용 — wb, rb처럼 조합해서 사용
⚠️ w 모드는 파일을 통째로 덮어써요
이미 있는 파일을 w로 열면 기존 내용이 즉시 사라집니다. 내용을 보존하며 덧붙이려면 a(추가 모드)를 쓰세요. 그리고 한글이 든 파일은 encoding='UTF8'을 지정해야 글자가 깨지지 않아요.

파일에 쓰기 (w · a)

python
f = open("sample.txt", "w")   # 쓰기 모드로 열기
print(f.writable())            # 쓸 수 있는 상태인지 확인
f.write("Hello\nWorld\n")      # 텍스트 쓰기 (쓴 글자 수를 반환)
f.close()                      # 반드시 닫기!
True

print() 함수의 file 인수에 파일 객체를 지정하면 화면 대신 파일로 출력됩니다.

python
f = open("sample.txt", "a")                  # 추가 모드
print("프린트 함수로 쓸 수 있습니다.", file=f)  # print로 파일에 쓰기
f.close()

파일 읽기 (r)

python
f = open("sample.txt", "r")    # 읽기 모드
lines = f.readlines()           # 모든 라인을 리스트로 한 번에
for line in lines:
    print(line.strip())         # strip(): 앞뒤 공백·줄바꿈 제거
f.close()
Hello World 프린트 함수로 쓸 수 있습니다.
💡 읽기 함수 3형제
read()는 파일 전체를 문자열 하나로, readline()은 한 줄씩, readlines()는 모든 줄을 리스트로 읽어요. 줄 끝의 \n이 함께 읽히므로 보통 strip()과 짝지어 씁니다.
💡 close()가 귀찮다면 — with (8장 복습)
with open("sample.txt") as f: 형태로 열면 블록이 끝날 때 자동으로 닫혀요. 닫기를 깜빡하는 실수를 원천 차단하므로 실무에선 with가 정석입니다. 이 장의 CSV·JSON 예제도 모두 with를 사용해요.

2형식이 있는 텍스트 데이터 다루기

실제 데이터 파일은 이렇게 구분자(delimiter)로 정리된 형식을 갖는 경우가 많아요.

📄 member.txt
홍길동,20,kildong@hong.com,서울시 강동구
홍길서,25,kilseo@hong.com,서울시 강서구

이런 데이터를 읽어 쓰려면 다음 4단계를 거칩니다.

  1. 한 라인씩 읽기 — readlines() 등으로
  2. 구분자로 분리 — 콤마(,) 기준 split(',')
  3. 자료형 변환 — 나이는 int()로 (파일에서 읽으면 전부 문자열!)
  4. 예외 처리 — 빠진 값(NA)이 있을 때를 대비 (8장 활용)
python
f = open("member.txt", "r", encoding='UTF8')
lines = f.readlines()
for line in lines:
    data = line.strip().split(',')   # 줄바꿈 제거 후 콤마로 분리
    name = data[0]
    age = int(data[1])               # 문자열 → 정수 변환
    email = data[2]
    address = data[3]
    print("이름 : {}, 나이 : {}, 이메일 : {}, 주소 : {}"
          .format(name, age, email, address))
f.close()
이름 : 홍길동, 나이 : 20, 이메일 : kildong@hong.com, 주소 : 서울시 강동구 이름 : 홍길서, 나이 : 25, 이메일 : kilseo@hong.com, 주소 : 서울시 강서구
⚠️ 파일에서 읽은 값은 전부 문자열이에요
data[1]은 "20"(문자열)이지 20(숫자)이 아니에요. 계산에 쓰려면 반드시 int()·float()로 변환해야 합니다. 이 번거로움을 덜어주는 게 뒤에 나올 피클·CSV 모듈이에요.

3피클(pickle) — 객체를 통째로 저장

🥒 피클링(Pickling)
파이썬 객체를 바이트 스트림으로 변환해 파일에 그대로 저장하는 것(객체 직렬화). 리스트·딕셔너리·직접 만든 클래스 객체까지 텍스트 변환 없이 통째로 저장됩니다.
🫙 비유 — 요리를 재료로 분해하지 않고 밀폐용기에 통째로 담아 냉동하는 것과 같아요. 나중에 꺼내면(언피클링) 조리 완료 상태 그대로 되살아나죠. split도 형 변환도 필요 없습니다.
구문
pickle.dump(obj, file)   # obj: 저장할 객체, file: 'wb' 모드로 연 파일 객체
data = pickle.load(file) # file: 'rb' 모드로 연 파일 객체
⚠️ 모드는 반드시 바이너리(b)!
피클은 이진 데이터라서 저장은 'wb'(바이너리 쓰기), 읽기는 'rb'(바이너리 읽기) 모드로 열어야 해요. 그냥 'w'로 열면 에러가 납니다. 시험에도 자주 나오는 포인트!

피클링 — 저장하기

python
class Member:                      # 고객 정보를 저장할 클래스
    def __init__(self, name, age, email, address):
        self.name = name
        self.age = age
        self.email = email
        self.address = address
    def __str__(self):
        return "Name:{}, Age:{}, Email:{}, Address:{}"\
               .format(self.name, self.age, self.email, self.address)

user1 = Member("홍길동", 20, "kildong@hong.com", "서울시 강동구")
user2 = Member("홍길서", 25, "kilseo@hong.com", "서울시 강서구")
user_list = [user1, user2]         # 저장할 데이터(객체 리스트)

import pickle
f = open("member.data", "wb")      # 바이너리 쓰기 모드!
pickle.dump(user_list, f)          # 리스트를 통째로 저장
f.close()
💡 저장된 파일을 메모장으로 열면?
사람이 읽을 수 없는 깨진 문자들이 보여요. 피클은 사람용이 아니라 파이썬 전용 형식이기 때문이에요. 사람이 읽어야 한다면 텍스트·CSV·JSON을 쓰세요.

언피클링 — 다시 불러오기

python
import pickle
f = open("member.data", "rb")      # 바이너리 읽기 모드!
user_list = pickle.load(f)         # 객체를 그대로 복원
print(type(user_list))             # 리스트 타입 그대로!

for user in user_list:
    print(user)                    # Member 객체의 __str__ 실행
f.close()
<class 'list'> Name:홍길동, Age:20, Email:kildong@hong.com, Address:서울시 강동구 Name:홍길서, Age:25, Email:kilseo@hong.com, Address:서울시 강서구
⚠️ 모르는 피클 파일은 열지 마세요
피클 파일은 로드 과정에서 코드가 실행될 수 있어, 출처를 믿을 수 없는 피클 파일을 load하면 보안 위험이 있어요. 내가 만든 파일, 신뢰할 수 있는 파일만 언피클링하세요.

4CSV 형식 파일 읽기/쓰기

📊 CSV (Comma Separated Values)
값을 콤마로 구분해 저장하는 표 형식 파일. 엑셀·데이터베이스와 데이터를 주고받을 때 가장 널리 쓰여요. 파이썬 기본 라이브러리의 csv 모듈로 다룹니다.
📋 비유 — 엑셀 시트를 가장 단순한 텍스트로 눌러 담은 것이에요. 한 줄이 한 행, 콤마가 셀 구분선. 그래서 메모장으로도 열리고 엑셀로도 열립니다.

reader() — 읽기

구문
csv.reader(csvfile, dialect='excel', **fmtparams)
# delimiter=','  : 필드 구분자 (기본 콤마)
# quotechar='"' : 값을 감싸는 인용 문자 (기본 큰따옴표)
# quoting=csv.QUOTE_NONNUMERIC : 숫자가 아닌 값만 인용 → 자동 형 변환
📄 member1.csv
"홍길동",20,"kildong@hong.com","서울시 강동구"
"홍길서",25,"kilseo@hong.com","서울시 강서구"
python
import csv
with open('member1.csv', 'r', encoding='UTF8') as csvfile:
    r = csv.reader(csvfile)
    for row in r:
        print(row)          # 각 행이 문자열 리스트로
['홍길동', '20', 'kildong@hong.com', '서울시 강동구'] ['홍길서', '25', 'kilseo@hong.com', '서울시 강서구']

나이가 '20'(문자열)로 읽혔죠? quoting=csv.QUOTE_NONNUMERIC을 지정하면 따옴표로 안 묶인 값을 숫자로 자동 변환해 줍니다.

python
import csv
with open('member1.csv', 'r', encoding='UTF8') as csvfile:
    r = csv.reader(csvfile, quotechar='"',
                   quoting=csv.QUOTE_NONNUMERIC)
    for row in r:
        print(row)
['홍길동', 20.0, 'kildong@hong.com', '서울시 강동구'] ['홍길서', 25.0, 'kilseo@hong.com', '서울시 강서구']
⚠️ 자동 형 변환의 함정
QUOTE_NONNUMERIC은 "따옴표 없는 값 = 숫자"로 간주해요. 그래서 홍길동,20,...처럼 문자 데이터가 따옴표 없이 저장된 파일에 쓰면 "홍길동을 숫자로 바꿀 수 없다"며 형 변환 에러가 납니다.

writer() — 쓰기

python
user_list = [['홍길동', 20.0, 'kildong@hong.com', '서울시 강동구'],
             ['홍길서', 25.0, 'kilseo@hong.com', '서울시 강서구']]

import csv
with open('member2.csv', 'w', newline='', encoding='UTF8') as csvfile:
    w = csv.writer(csvfile, quoting=csv.QUOTE_NONNUMERIC)
    w.writerows(user_list)      # 모든 행을 한 번에 저장
"홍길동",20.0,"kildong@hong.com","서울시 강동구" "홍길서",25.0,"kilseo@hong.com","서울시 강서구"
💡 newline=''을 꼭 쓰세요
윈도우에서 newline='' 없이 CSV를 쓰면 행마다 빈 줄이 하나씩 끼어드는 유명한 버그가 생겨요. CSV를 쓸 때는 습관처럼 open(..., 'w', newline='')! 한 행씩 저장할 땐 writerow(), 여러 행은 writerows()입니다.

DictReader — 딕셔너리로 읽기

🏷️ DictReader
CSV의 첫 줄(헤더)을 열 이름으로 삼아, 각 행을 딕셔너리로 돌려줘요. row[2] 대신 row["Email"]처럼 이름으로 접근할 수 있어 훨씬 읽기 좋습니다.
📄 member3.csv
Name,Age,Email,Address
홍길동,20,kildong@hong.com,서울시 강동구
홍길서,25,kilseo@hong.com,서울시 강서구
python
import csv
with open('member3.csv', encoding='UTF8') as csvfile:
    dict_reader = csv.DictReader(csvfile)
    for row in dict_reader:
        print(row["Name"], row["Age"], row["Email"], row["Address"])
홍길동 20 kildong@hong.com 서울시 강동구 홍길서 25 kilseo@hong.com 서울시 강서구
💡 버전에 따른 출력 차이
행을 통째로 print(row)하면 예전 파이썬(~3.7)은 OrderedDict([...]), 3.8 이상은 일반 딕셔너리 {'Name': '홍길동', ...}로 보여요. 사용법은 같으니 교재 스크린샷과 달라도 놀라지 마세요.

헤더가 없거나 필드 수가 안 맞는 파일을 위한 옵션 3가지도 알아두세요.

옵션상황동작
fieldnames파일에 헤더가 없을 때열 이름을 직접 지정
restkey데이터가 필드 이름보다 많을 때남는 값들을 지정한 키에 리스트로 저장
restval데이터가 필드 이름보다 적을 때비는 자리를 지정한 값으로 채움
python
# 헤더 없는 member1.csv에 이름 붙여 읽기 + 남는 값 처리
with open('member1.csv', encoding='UTF8') as csvfile:
    dict_reader = csv.DictReader(csvfile,
                    fieldnames=["Name", "Age", "Email"],  # 3개만 지정
                    restkey="Etc")                        # 남는 건 Etc로
    for row in dict_reader:
        print(row["Name"], row["Age"], row["Email"], row["Etc"])
홍길동 20 kildong@hong.com ['서울시 강동구'] 홍길서 25 kilseo@hong.com ['서울시 강서구']

DictWriter — 딕셔너리로 쓰기

python
user1 = {"Name":"홍길동", "Age":20, "Email":"kildong@hong.com",
         "Address":"서울시 강동구"}
user2 = {"Name":"홍길서", "Age":25, "Email":"kilseo@hong.com",
         "Address":"서울시 강서구"}

import csv
with open('member4.csv', 'w', newline='', encoding='utf8') as csvfile:
    fieldnames = ['Name', 'Age', 'Email', 'Address']
    dict_writer = csv.DictWriter(csvfile, fieldnames=fieldnames)
    dict_writer.writeheader()          # 헤더(열 이름) 한 줄 쓰기
    dict_writer.writerow(user1)        # 한 행씩 저장
    dict_writer.writerow(user2)        # writerows([user1, user2])도 가능
Name,Age,Email,Address 홍길동,20,kildong@hong.com,서울시 강동구 홍길서,25,kilseo@hong.com,서울시 강서구

딕셔너리에 fieldnames에 없는 키가 들어 있으면? extrasaction 옵션이 결정해요.

python
# fieldnames에 Address가 없는 상태로 저장 시도
with open('member5.csv', 'w', newline='', encoding='utf8') as csvfile:
    fieldnames = ['Name', 'Age', 'Email']
    dict_writer = csv.DictWriter(csvfile, fieldnames=fieldnames)
    dict_writer.writeheader()
    dict_writer.writerows([user1, user2])   # Address가 남는다!
ValueError: dict contains fields not in fieldnames: 'Address'
💡 extrasaction 두 가지
기본값 extrasaction='raise'는 위처럼 ValueError를 발생시키고, extrasaction='ignore'로 지정하면 남는 값을 조용히 무시하고 저장합니다.

5JSON 데이터 저장하고 불러오기

🌐 JSON (JavaScript Object Notation)
웹에서 데이터를 주고받는 표준 텍스트 형식이에요. 사람이 읽을 수 있으면서 구조(중첩)도 표현할 수 있어, 설정 파일·API 응답 등에 널리 쓰입니다. json 모듈로 다뤄요.

json.dump() — 저장

python
data = ['foo', {'bar': ('baz', None, 1.0, 2)}]

import json
with open('sample.json', 'w') as jsonfile:
    json.dump(data, jsonfile, indent='\t')   # indent: 들여쓰기로 보기 좋게

튜플은 배열로, None은 null로 바뀐 게 보이죠? 그런데 직접 만든 클래스 객체는 JSON이 모르는 타입이라 그냥 저장하면 에러가 나요. default 인수에 "객체 → 딕셔너리" 변환 함수를 알려주면 해결됩니다.

python
class Member:
    def __init__(self, name, age, email, address):
        self.name = name
        self.age = age
        self.email = email
        self.address = address
    def as_dict(self):                  # 객체를 딕셔너리로 변환
        return {"name":self.name, "age":self.age,
                "email":self.email, "address":self.address}

user_list = [Member("홍길동", 20, "kildong@hong.com", "서울시 강동구"),
             Member("홍길서", 25, "kilseo@hong.com", "서울시 강서구")]

import json
with open('member.json', 'w', encoding="UTF8") as jsonfile:
    json.dump(user_list, jsonfile, ensure_ascii=False,
              indent="\t", default=Member.as_dict)   # 변환 방법 지정
[ { "name": "홍길동", "age": 20, "email": "kildong@hong.com", "address": "서울시 강동구" }, ... ]
💡 한글은 ensure_ascii=False
기본값(True)이면 한글이 홍길동 같은 유니코드 코드로 저장돼요. ensure_ascii=False로 지정해야 한글이 그대로 저장됩니다.

json.load() — 불러오기

python
import json
with open('member.json', encoding="UTF8") as jsonfile:
    user_list = json.load(jsonfile)    # JSON → 파이썬 객체
    print(user_list[0])
{'name': '홍길동', 'age': 20, 'email': 'kildong@hong.com', 'address': '서울시 강동구'}

기본으로는 딕셔너리로 읽혀요. 딕셔너리가 아니라 Member 객체로 바로 되살리고 싶다면 object_hook에 "딕셔너리 → 객체" 함수를 지정합니다.

python
def as_member(dct):                    # 딕셔너리를 Member 객체로
    return Member(dct['name'], dct['age'], dct['email'], dct['address'])

with open('member.json', encoding="UTF8") as jsonfile:
    user_list = json.load(jsonfile, object_hook=as_member)
    for user in user_list:
        print(user)                    # Member의 __str__ 출력
Name:홍길동, Age:20, Email:kildong@hong.com, Address:서울시 강동구 Name:홍길서, Age:25, Email:kilseo@hong.com, Address:서울시 강서구
💡 또 다른 방법 — JSONEncoder 상속
json.JSONEncoder를 상속해 default() 메서드를 재정의한 클래스를 만들고 json.dump(..., cls=MemberEncoder)처럼 넘겨도 돼요. 객체를 리스트로 반환하면 JSON 배열로 저장됩니다. 7장(상속)의 응용이에요!

정답 (전체 코드 — 실행 검증 완료)
python
import os

class Customer:
    "고객 정보를 담는 클래스"
    def __init__(self, name, phone, email, age, grade, etc):
        self.name = name
        self.phone = phone
        self.email = email
        self.age = age
        self.grade = grade
        self.etc = etc

    def to_txt_style(self):
        "파일 저장용: 홍길동,010-9999-9999,e@e.com,32,4,동해번쩍"
        return "{},{},{},{},{},{}".format(self.name, self.phone,
                self.email, self.age, self.grade, self.etc)

    def as_dic(self):
        "CSV(DictWriter) 저장용 딕셔너리로 반환"
        return {"name":self.name, "phone":self.phone, "email":self.email,
                "age":self.age, "grade":self.grade, "etc":self.etc}

    def __str__(self):
        "출력용: **** 홍길동 010-9999-9999 hong@h.co.kr 32 동해번쩍"
        return "{:>5}\t{:3}\t{:13}\t{:15}\t{}\t{}".format(
            "*"*self.grade, self.name, self.phone,
            self.email, self.age, self.etc)

def to_customer(row):
    "텍스트 한 줄을 Customer 객체로 변환"
    data = row.strip().split(',')
    return Customer(data[0], data[1], data[2],
                    int(data[3]), int(data[4]), data[5])

def load_customers():
    "0. 시작 시 파일 로드 (없으면 빈 파일 생성)"
    customer_list = []
    if os.path.exists('data/ch09_customers.txt'):
        with open('data/ch09_customers.txt', 'r', encoding='utf8') as f:
            for line in f.readlines():
                customer_list.append(to_customer(line))
        print('데이터가 로드 되었습니다.')
    else:
        os.makedirs('data', exist_ok=True)
        f = open('data/ch09_customers.txt', 'w', encoding='utf8')
        f.close()
        print('데이터 파일 ch09_customers.txt가 없어서 초기화합니다')
    return customer_list

def fn1_insert_customer_info():
    "1. 고객 정보를 입력받아 Customer 객체로 반환"
    name = input('이름 :')
    phone = input('전화 :')
    email = input('메일 :')
    while True:
        try:
            age = int(input('나이 :'))
            break
        except ValueError:              # 8장 예외처리 활용!
            print('나이는 숫자로 입력하세요')
    while True:
        try:
            grade = int(input('등급(1~5) : '))
            if 1 <= grade <= 5:
                break
        except ValueError:
            pass
        print('등급은 1~5 사이 숫자로 입력하세요')
    etc = input('기타 정보 :')
    return Customer(name, phone, email, age, grade, etc)

def fn2_print_customers(customer_list):
    "2. 전체 고객 출력"
    print('=' * 70)
    print('{:^66}'.format('고 객   정 보'))
    print('-' * 70)
    print('{:>5} {:>4}\t{:13}\t{:15}\t{}\t{}'.format(
        'GRADE', '이름', '전화', '메일', '나이', '기타'))
    print('-' * 70)
    for customer in customer_list:
        print(customer)

def fn3_save_customer_txt(customer_list):
    "3. data/ch09_customers.txt에 백업"
    lines = [customer.to_txt_style() + '\n' for customer in customer_list]
    with open('data/ch09_customers.txt', 'w', encoding='utf8') as f:
        f.writelines(lines)
    print('백업(data/ch09_customers.txt) 후 종료합니다')

def main():
    global customer_list
    customer_list = load_customers()
    while True:
        print("1:입력", "2:전체출력", "3:데이터백업후 종료",
              sep=' | ', end=' ')
        fn = int(input('메뉴선택 : '))
        if fn == 1:
            customer_list.append(fn1_insert_customer_info())
        elif fn == 2:
            fn2_print_customers(customer_list)
        elif fn == 3:
            fn3_save_customer_txt(customer_list)
            break

if __name__ == '__main__':
    main()

이 프로그램은 지금까지 배운 것의 종합 선물세트예요. ① 7장 클래스로 고객 정보를 객체로 묶고, ② 이번 장 파일 입출력으로 프로그램을 꺼도 데이터가 유지되게 하고(to_txt_style() ↔ to_customer()가 저장·복원의 짝), ③ 8장 예외처리로 잘못된 입력을 막습니다. 핵심 흐름은 시작할 때 load → 메모리(리스트)에서 작업 → 끝낼 때 save — 대부분의 데이터 프로그램이 이 구조를 따라요. 두 번째 실행에서 "데이터가 로드 되었습니다."와 함께 이전 고객이 그대로 나오면 성공!
