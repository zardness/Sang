1판다스 패키지

🐼 판다스(Pandas)
표(테이블) 형태 데이터를 다루는 파이썬의 표준 데이터 분석 도구. 1차원 구조 시리즈(Series)와 2차원 구조 데이터프레임(DataFrame)을 제공하며, 조회·추가/삭제·병합·구조 변경·결측치 처리 등 데이터 전처리의 거의 모든 기능을 갖췄어요.
📊 비유 — 데이터프레임은 엑셀 시트 한 장, 시리즈는 그 시트의 한 열(column)이에요. 엑셀에서 마우스로 하던 필터·정렬·피벗을 코드로, 그것도 수백만 행에서 순식간에 해냅니다.

데이터프레임의 구조부터 눈에 익히세요. 행(row)과 열(column)마다 이름과 인덱스(위치)가 있습니다.

EMPNOENAMESALARYDEPTNO
07369SMITH5500.010
17499ALLEN8900.030
27521WARDNaN10
37566JONES9500.020
  • 행(Row) — 데이터 1건. 서로 다른 타입의 값을 가질 수 있음. 세로 방향이 axis=0
  • 열(Column) — 하나의 변수. 열 안의 데이터는 모두 같은 타입. 가로 방향이 axis=1. 열 하나를 꺼내면 그게 시리즈!
  • NaN — 비어 있는 값(결측치). 판다스는 결측치 처리 기능이 잘 갖춰져 있어요 (11절에서!)
💡 판다스 파일 입출력 — read_○○ / to_○○ 짝 외우기
CSV는 read_csv() ↔ to_csv(), 엑셀은 read_excel() ↔ to_excel(), JSON은 read_json() ↔ to_json(), HTML 표는 read_html() ↔ to_html(), HDF5는 read_hdf() ↔ to_hdf(), 피클은 read_pickle() ↔ to_pickle(). 9장에서 모듈별로 하던 일을 판다스는 일관된 함수 이름으로 통일해 줍니다.
💡 출력이 ...으로 잘릴 때 — 디스플레이 옵션
행·열이 많으면 일부만 표시되고 가운데가 ...이 돼요. pd.options.display.max_columns = 999처럼 max_rows·max_columns·max_colwidth·precision(소수 자릿수) 옵션으로 조절할 수 있습니다.

loc — 이름으로 / iloc — 위치(정수)로

🎯 loc[행이름, 열이름] vs iloc[행위치, 열위치]
loc은 이름(라벨) 기준, iloc은 정수 인덱스 기준으로 찾아요. 이름 하나·리스트·슬라이스 모두 쓸 수 있고, 열 지정은 생략 가능(행 전체).
🏠 비유 — loc은 "'홍길동 씨' 댁이요"(문패로 찾기), iloc은 "3번째 집이요"(순번으로 찾기). 같은 집을 두 방식으로 찾을 수 있죠.
python
member_df.loc[0:2]                        # 행 이름 0~2 (loc은 끝 포함!)
member_df.loc[0:2, "Name":"Email"]        # 슬라이싱으로
member_df.loc[[0, 2], ["Name", "Email"]]  # 리스트로 콕 집어
Name Email 0 홍길동 kildong@hong.com 2 홍길남 south@hong.com
python
member_df.iloc[1:3, 1:3]     # 1~2행, 1~2열 (iloc은 끝 미포함!)
member_df.iloc[::-1]          # 행 역순
member_df.iloc[0::2, [1, 3]]  # 짝수 행의 1·3열
Age Email 1 25 kilseo@hong.com 2 26 south@hong.com
⚠️ loc은 끝을 포함, iloc은 미포함
loc[0:2]는 3행(0,1,2), iloc[0:2]는 2행(0,1)이에요. loc은 "이름 슬라이싱"이라 양 끝을 포함한다고 기억하세요. 시험·실무 모두에서 단골 함정!

5데이터 삭제와 추가

drop() — 행·열 삭제

구문
DataFrame.drop(labels, axis=0, inplace=False)
# labels : 삭제할 행/열 이름 (리스트 가능)
# axis   : 0이면 행에서, 1(또는 'columns')이면 열에서 찾아 삭제
# inplace: True면 원본을 직접 수정(반환 None), False면 결과를 반환
python
member_df.drop('북')                              # 행 '북' 삭제 (axis=0 기본)
member_df.drop('주소', axis=1)                     # 열 '주소' 삭제
member_df.drop(labels=["Email", "Address"], axis=1)  # 여러 열 한 번에
member_df.drop("Address", axis=1, inplace=True)    # 원본에서 바로 삭제
Name Age Email 0 홍길동 20 kildong@hong.com 1 홍길서 25 kilseo@hong.com 2 홍길남 26 south@hong.com 3 홍길북 27 book@hong.com
💡 drop은 기본적으로 "새 결과를 반환"
inplace=False(기본값)면 원본은 그대로고 삭제된 결과가 반환돼요. 그래서 member_df = member_df.drop('북')처럼 재할당하거나 inplace=True를 쓰는 두 가지 스타일이 있습니다.

6데이터프레임 병합과 연결

merge() — 공통 열(키)을 기준으로 합치기 (조인)

🔗 merge()
두 데이터프레임의 공통 열(또는 인덱스)을 기준으로 옆으로 합쳐요. 데이터베이스의 조인(join)과 같은 개념입니다.
🧩 비유 — '학번'이 적힌 성적표와 '학번'이 적힌 주소록을 학번 기준으로 맞춰 한 장으로 만드는 것. 어느 쪽에만 있는 학생을 남길지(how)가 선택 포인트예요.
python
df1 = pd.DataFrame({'key': ['a', 'b', 'c', 'f'], 'c1': [1, 2, 3, 5]})
df2 = pd.DataFrame({'key': ['a', 'b', 'd', 'f'], 'c2': [5, 6, 7, 8]})

df1.merge(df2)                 # 기본 how='inner': 양쪽에 다 있는 키만
df1.merge(df2, how="left")     # 왼쪽(df1) 키는 전부 유지
df1.merge(df2, how="outer")    # 양쪽 키 전부 (없는 곳은 NaN)
key c1 c2 key c1 c2 key c1 c2 0 a 1 5 0 a 1 5.0 0 a 1.0 5.0 1 b 2 6 1 b 2 6.0 1 b 2.0 6.0 2 f 5 8 2 c 3 NaN 2 c 3.0 NaN (inner) 3 f 5 8.0 3 d NaN 7.0 (left) 4 f 5.0 8.0 (outer)
how남기는 키비유
inner (기본)양쪽 모두에 있는 키교집합
left / right왼쪽/오른쪽 키 전부한쪽 기준
outer양쪽 키 전부합집합 (빈 곳 NaN)

기준 열의 이름이 서로 다르면 left_on·right_on으로 지정합니다.

python
df3 = pd.DataFrame({'key3': ['a', 'b', 'c', 'f'], 'c1': [1, 2, 3, 5]})
df4 = pd.DataFrame({'key4': ['a', 'b', 'd', 'f'], 'c2': [5, 6, 7, 8]})
df3.merge(df4, left_on="key3", right_on="key4")

concat() — 그냥 이어붙이기

python

c1 c2 c3 c4 0 1 5 a 1.2 1 2 6 b 3.4 2 3 7 c 5.5 3 4 8 d 7.6
⚠️ concat의 두 가지 주의점
① axis=0(아래로)일 때 열 이름이 다르면 없는 곳이 전부 NaN이 돼요. ② 연결은 인덱스를 기준으로 짝을 맞추므로, 두 데이터프레임의 인덱스가 다르면(예: 0,2,4,6 vs 0,1,2,3) 결과가 어긋납니다. 이럴 땐 df.reset_index(drop=True)로 인덱스를 0부터 초기화한 뒤 연결하세요.
💡 merge vs concat 선택법
공통 키로 맞춰 합친다 → merge. 구조가 같은(또는 이어붙일) 데이터를 단순 연결 → concat. "월별 판매 파일 12개를 아래로 잇기"는 concat, "고객정보에 구매정보 붙이기"는 merge입니다.
