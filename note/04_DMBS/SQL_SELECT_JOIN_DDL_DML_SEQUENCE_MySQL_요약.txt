1장 SELECT 기본 조회 (0819_02_SELECT.sql)
    -SELECT 열 FROM 테이블 WHERE 조건 ORDER BY 정렬기준 형태로 조회
    -SELECT *: 모든 열, 특정 열 이름 나열: 필요한 열만 조회
    -AS로 출력 제목 지정, DISTINCT로 선택한 열 조합의 중복 제거
    -WHERE에서 =, <>, >, <, >=, <=와 AND, OR, NOT으로 조건 작성
    -ORDER BY의 기본은 ASC(오름차순), DESC는 내림차순
    -정렬 기준을 여러 개 쓰면 앞 기준이 같은 행에 다음 기준 적용
    -DESC EMP는 테이블 구조 확인, SELECT * FROM TAB은 Oracle 계정의 테이블 등 확인

2장 조건 연산자와 NULL 처리
    -BETWEEN A AND B: 양 끝값 포함 범위, NOT BETWEEN: 해당 범위 밖
    -IN(값1,값2): 목록에 포함되는 값, NOT IN: 목록에 없는 값
    -LIKE 'M%': M으로 시작, '%N%': N 포함, '__N%': 세 번째 문자가 N
    -LIKE의 %는 0개 이상 문자, _는 문자 하나
    -NULL 검사는 IS NULL 또는 IS NOT NULL 사용
    -NULL은 0이나 문자열 'NULL'과 다르며 = NULL로 비교하지 않음
    -Oracle NVL(COMM,0): 상여금이 NULL이면 0으로 대체
    -연봉 예제는 SAL*12+NVL(COMM,0)과 (SAL+NVL(COMM,0))*12를 문제 조건에 맞게 구분

3장 Oracle 문자열·날짜·숫자 처리
    -|| 연산자로 열 값과 문자열 연결
    -TO_CHAR(): 날짜나 숫자를 지정한 형식의 문자열로 변환
    -TO_DATE('2026-08-19','YYYY-MM-DD'): 문자열을 날짜로 변환
    -날짜 형식: YYYY 연도, MM 월, DD 일, HH24 시, MI 분, SS 초
    -SYSDATE: 현재 날짜와 시간
    -문자열 날짜의 암묵적 변환은 세션 설정에 영향을 받으므로 형식 명시
    -연도 범위는 해당 연도 1월 1일 이상, 다음 연도 1월 1일 미만으로 비교하면 시간값까지 포함 가능

4장 JOIN의 종류 (0820_03_JOIN.sql)
    -CROSS JOIN: 두 테이블의 모든 행 조합 생성
    -EQUI JOIN: 같은 값으로 연결, 예: E.DEPTNO=D.DEPTNO
    -NON-EQUI JOIN: 범위 등 동등 비교 외 조건으로 연결, 예: SAL BETWEEN LOSAL AND HISAL
    -SELF JOIN: 같은 테이블에 별칭을 달아 직원과 상사처럼 연결
    -예: EMP W, EMP M에서 W.MGR=M.EMPNO로 상사 이름 조회
    -OUTER JOIN: 연결되는 상대 행이 없어도 보존할 쪽의 행을 출력
    -Oracle 예제 W.MGR=M.EMPNO(+)는 상사 없는 직원도 포함
    -표준 문법: EMP W LEFT JOIN EMP M ON W.MGR=M.EMPNO
    -부서, 급여등급, 상사 정보를 함께 조인하여 종합 사원 정보 출력

5장 DDL과 자료형 (0821_04_DDL_DML.sql)
    -CREATE TABLE: 테이블 생성, ALTER TABLE: 구조 변경, DROP TABLE: 테이블 삭제
    -Oracle NUMBER(p,s): 전체 유효 자릿수 p, 소수 자릿수 s
    -VARCHAR2: 가변 길이 문자열, DATE: 날짜와 시간, CLOB: 큰 문자열
    -CREATE TABLE ... AS SELECT ...: 조회 결과로 새 테이블 생성
    -위 복사 방식은 PK·FK·UNIQUE 등 원본 제약조건을 모두 복사하지는 않음
    -DROP TABLE ... CASCADE CONSTRAINTS는 참조 제약조건도 제거하며 참조 테이블 자체를 삭제하는 것은 아님

6장 제약조건과 기본값
    -PRIMARY KEY: 각 행 식별, 중복과 NULL 불가
    -FOREIGN KEY: 다른 테이블의 키를 참조하여 관계 유지
    -NOT NULL: 반드시 값 입력
    -UNIQUE: 중복값 제한, 예제의 단일 열에서는 여러 NULL 허용
    -CHECK(SAL>0): 입력값 조건 검사, NULL 금지는 별도 NOT NULL 필요
    -DEFAULT SYSDATE: 해당 열을 생략하면 현재 날짜·시간 입력
    -부서 먼저 입력 후 사원 입력 등 외래키 관계를 고려한 순서 필요

7장 DML과 트랜잭션
    -INSERT INTO 테이블(열목록) VALUES(값목록): 행 추가
    -INSERT INTO 테이블 SELECT ...: 조회 결과를 여러 행으로 추가
    -UPDATE 테이블 SET 열=값 WHERE 조건: 조건에 맞는 행 수정
    -DELETE FROM 테이블 WHERE 조건: 조건에 맞는 행 삭제
    -UPDATE·DELETE에서 WHERE를 생략하면 전체 행이 대상
    -서브쿼리로 부서번호나 상사 사번을 조회해 수정·삭제 조건에 활용
    -COMMIT: 트랜잭션 확정, ROLLBACK: 아직 확정하지 않은 변경 취소
    -COMMIT·ROLLBACK은 트랜잭션 제어 명령(TCL)로 구분
    -Oracle DDL은 암묵적 COMMIT을 수반하므로 DML처럼 ROLLBACK으로 되돌릴 수 없음

8장 Oracle 시퀀스 (0821_05_SEQUENCE.sql)
    -CREATE SEQUENCE로 번호 생성기를 만들어 인위적인 기본키 등에 사용
    -START WITH: 시작값, INCREMENT BY: 증가폭
    -MINVALUE·MAXVALUE: 값 범위, NOCYCLE: 최대값 이후 순환하지 않음
    -NOCACHE: 시퀀스 번호를 미리 캐시하지 않도록 설정
    -NEXTVAL: 다음 번호 생성, CURRVAL: 현재 세션에서 마지막으로 얻은 번호
    -CURRVAL은 해당 세션에서 NEXTVAL을 먼저 사용한 뒤 조회 가능
    -INSERT에서 FRIEND_NO_SEQ.NEXTVAL로 친구 번호 자동 입력
    -시퀀스 번호는 롤백으로 반환되지 않아 중간 번호가 비어 있을 수 있음

9장 MySQL 계정·테이블·조회 (0824_MySQL.sql)
    -CREATE USER, GRANT, REVOKE, DROP USER로 계정과 권한 관리
    -CREATE DATABASE로 DB 생성, SHOW DATABASES로 목록 확인, USE로 선택
    -SHOW TABLES: 테이블 목록, SELECT DATABASE(): 현재 DB 확인
    -자료형 예: INT, NUMERIC(p,s), VARCHAR(n), DATE, DATETIME
    -AUTO_INCREMENT로 정수 키 자동 증가, 예제 friend 테이블의 no에 적용
    -IFNULL(COMM,0)은 예제에서 Oracle NVL과 같은 NULL 대체 역할
    -LEFT JOIN으로 상사 없는 직원도 포함하고 IFNULL로 CEO 문구 출력
    -문자열 연결은 CONCAT(), 숫자 표시 형식은 FORMAT(숫자,소수자릿수)
    -DATE_FORMAT()으로 날짜 표시 형식 지정, 분은 %i 사용
    -MySQL의 ||는 기본 설정에서 OR이므로 문자열 연결에는 CONCAT() 사용

10장 사원·부서 입력 데이터 (0824.person_insert.txt)
    -division 테이블에 부서 4개, person 테이블에 사원 10명 입력하는 자료
    -person의 dno가 division의 dno를 참조
    -사번, 이름, 직무, 상사 사번, 입사일, 급여, 상여금, 부서번호 순서
    -앞부분은 탭 구분 원시 데이터이며 \N으로 NULL을 표시
    -뒷부분은 같은 사원 데이터와 부서 데이터를 INSERT SQL로 제공
    -탭 구분 자료와 SQL 구문이 섞여 있어 파일 전체를 SQL로 실행하면 안 됨

11장 소스에서 확인할 주요 오류
    -SELECT 연봉 조건의 SAL*12(COMM,0)은 SAL*12+NVL(COMM,0)으로 수정 필요
    -TO_CHAR(HIREDATE,...)<81/01/01의 오른쪽은 날짜가 아닌 나눗셈 식: 날짜끼리 비교 필요
    -JOIN의 DEPT.DEPINO는 DEPT.DEPTNO 오타, SELECT EMPNO, ENAME, FROM의 마지막 쉼표 제거 필요
    -JOIN 파일의 Part1(...), Part2(...) 안내 문장은 SQL 주석 처리 필요
    -BOOK 생성문은 PRIMARY KEY 중복 지정 또는 마지막 열 뒤 쉼표로 오류 발생
    -숫자·날짜 열에 문자열 'NULL'을 넣지 말고 따옴표 없는 NULL 사용
    -급여 3000 이상 조건인데 SAL<3000 또는 SAL<=3000으로 작성된 실습은 조건 수정 필요
    -상여금이 없는 사원 문제에 IS NOT NULL AND COMM!=0을 쓴 부분은 조건이 반대
    -일부 문제는 요청한 열이나 ORDER BY가 빠져 있어 문제 설명과 비교 필요
    -MySQL 사번 출력에는 manager가 아닌 pno 사용
    -MySQL 날짜 출력의 date pname, date_format(hireddate,...)는 SELECT pname, DATE_FORMAT(hiredate,...)로 수정 필요
    -자료형 주석의 varchra, dediumint, intger는 각각 VARCHAR, MEDIUMINT, INTEGER 오타
    -이 자료는 오류·제약조건 위반 실습과 DROP 구문이 함께 있으므로 구문별로 구분해 학습
