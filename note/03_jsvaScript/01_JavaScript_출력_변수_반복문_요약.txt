1장 JavaScript 작성과 출력
    -<script> ... </script> : HTML 안에 JavaScript 작성
    -document.write() : 문서에 문자열이나 HTML 출력
    -일반 script는 문서를 읽는 과정에서 만나는 순서대로 실행
    -1_firstEx.html : HTML과 JavaScript를 섞어 첫 번째~일곱 번째 메시지 출력
    -// : 한 줄 주석 / /* ... */ : 여러 줄 주석

2장 외부 JavaScript 연결
    -<script src="파일.js"></script> : 외부 JavaScript 파일 실행
    -2_consol.html : 외부 스크립트를 먼저 실행한 뒤 i와 sum을 화면에 출력
    -첨부 파일은 2(1).js이므로 src="2(1).js"로 맞추거나 파일명을 2.js로 변경
    -이전에 올린 2.js는 이름 입력 예제이므로 이번 반복문 파일과 구분

3장 변수 선언과 범위
    -let sum = 0; : 변경 가능한 변수 sum을 0으로 초기화
    -var : 함수 범위 변수 / let·const : 블록 범위 변수
    -var가 항상 전역변수, let이 항상 지역변수인 것은 아님
    -const : 재할당할 수 없는 변수 선언
    -예제의 var i는 for 블록 밖에서도 접근 가능
    -for (let i=1; ...)로 바꾸면 해당 i는 반복문 밖에서 접근 불가

4장 for 반복문과 누적합
    -for (초기화; 조건; 증감) { 반복할 코드 }
    -var i=1 : 1부터 시작 / i<=5 : 5 이하일 때 반복 / i++ : 1 증가
    -sum += i; : sum = sum + i;와 같은 누적 계산
    -반복 중 sum : 1 → 3 → 6 → 10 → 15
    -반복 종료 후 sum은 15, i는 조건 검사에서 탈락한 값 6

5장 콘솔 출력과 화면 출력
    -console.log() : 개발자 도구 Console에 값 출력
    -쉼표로 여러 값을 전달하거나 +로 문자열과 값을 연결
    -document.write() : 브라우저 문서에 출력
    -외부 파일이 올바르게 연결되면 원본은 '6까지 누적된 최종합은15'라고 출력
    -실제 합은 1~5의 합이므로 '1부터 5까지의 합은 ' + sum으로 문구 수정

6장 원본 코드의 수정 사항
    -1_firstEx.html : 출력 문자열의 제목 태그를 <h2>내용</h2>로 통일
    -</html> 뒤의 script는 </body> 앞 등 문서 내부로 이동
    -2_consol.html : src와 실제 반복문 파일 이름을 일치시켜야 정상 실행
    -document.write()는 학습용 출력 방식이며 문서 로딩 후 호출하면 내용을 덮어쓸 수 있음
