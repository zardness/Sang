1장 if 조건문
    -if(조건) : 조건이 참이면 실행 / else if : 앞 조건이 거짓일 때 다음 조건 검사
    -else : 앞의 조건이 모두 거짓일 때 실행
    -new Date() : 현재 날짜·시간 객체 / getHours() : 실행 환경의 현지 시각, 0~23
    -1_if(2).html : 0~11시는 오전 문구·이미지, 12~19시는 오후 문구·이미지 출력
    -20~23시는 처리하는 조건이 없어 아무 내용도 출력되지 않음
    -12 <= hour && hour < 20 : 두 조건을 모두 만족하는 시간 범위

2장 switch와 요일별 배경색
    -switch(값) : 일치하는 case부터 실행 / case는 자료형까지 구분하여 비교
    -break : switch 종료 / default : 일치하는 case가 없을 때 실행
    -break가 없으면 다음 case의 코드로 이어서 실행될 수 있음
    -getDay() : 요일 번호, 일요일 0 ~ 토요일 6
    -예제 의도 : 일 빨강 / 월 주황 / 화 노랑 / 수 초록 / 목 파랑 / 금 남색 / 토 보라
    -배경색 지정 예 : document.body.style.backgroundColor = 'orange';

3장 switch로 짝수·홀수 판별
    -prompt() : 문자열 입력, 취소하면 null / parseInt() : 정수 부분 변환
    -su % 2 : 2로 나눈 나머지
    -case 0 : 짝수 / case 1·case -1 : 홀수, 음수도 처리
    -case 1 다음에 실행문 없이 case -1을 두어 같은 코드 사용
    -변환 결과가 NaN이면 default에서 입력 오류 안내
    -parseInt('3.9',10)은 3, parseInt('3점',10)도 3이므로 엄격한 정수 검사는 아님

4장 삼항 연산자
    -조건 ? 참일 때 값 : 거짓일 때 값
    -difference = num1 > num2 ? num1-num2 : num2-num1;
    -큰 수에서 작은 수를 빼 두 수의 차이 계산
    -중첩 삼항 연산자로 첫 번째가 큼·두 번째가 큼·같음을 구분
    -3_삼항연산자.js : 두 수가 모두 20이므로 차이는 0, 같다는 문구 출력
    -백틱과 ${difference} : 문자열 안에 계산값 삽입

5장 짧은 조건문과 단락 평가
    -조건 && 실행문 : 왼쪽이 참으로 해석될 때만 오른쪽 실행
    -조건 || 실행문 : 왼쪽이 거짓으로 해석될 때만 오른쪽 실행
    -(su%2==0) && alert('짝수입니다.'); : 짝수 조건일 때 알림
    -(su%2==0) || alert('홀수입니다.'); : 짝수 조건이 거짓일 때 알림
    -&&·||는 항상 boolean만 반환하는 것이 아니라 피연산자 값을 반환

6장 두 수 비교 실습 (5_quiz.html)
    -onsubmit="return chk()" : 제출할 때 검사 함수 실행
    -frm.su1.value·frm.su2.value : 입력창 값 읽기 / Number() : 숫자 변환
    -빈 입력이면 안내 후 return false로 제출 중단
    -삼항 연산자로 차이 계산, if·else if·else로 크기 관계 판별
    -alert()와 document.write()로 결과 출력 / 마지막 return false로 기본 제출 방지
    -input type="number" : 숫자 입력 양식, 소수 허용 시 step="any" 등 설정 필요

7장 원본 코드의 주의사항
    -요일 예제 : 'background-color: :색상;'에서 중복 콜론 제거
    -document.bgColor 대신 document.body.style.backgroundColor로 통일 가능
    -body 조작 코드는 </body> 앞이나 로딩 완료 함수 안에서 실행하면 명확함
    -짧은 조건문 예제 : 취소·빈 문자열·공백은 Number()에서 0이 되어 짝수로 표시됨
    -숫자가 아닌 값이나 소수도 짝수 조건이 거짓이면 홀수로 표시되는 문제 있음
    -취소·공백을 먼저 확인하고 Number.isInteger()로 정수 여부 검사 후 홀짝 판별
    -5_quiz.html : 제출 후 document.write()는 기존 폼을 포함한 문서를 덮어쓸 수 있음
    -결과 표시 요소를 따로 만들고 textContent로 내용을 바꾸는 방식 사용 가능
