1장 window 객체와 이벤트 (1_window객체의속성.html)
    -window는 브라우저 창의 전역 객체로 alert, confirm 등의 기능 제공
    -window.alert()는 alert()처럼 window를 생략하여 사용 가능
    -for-in문으로 window의 열거 가능한 속성을 순회
    -key.substr(0,2)=='on'으로 이름이 on으로 시작하는 이벤트 속성 확인
    -window.onclick에 함수를 할당하면 클릭 이벤트가 전달될 때 실행
    -예제의 일반 script 최상위에서 var로 선언한 cnt, chk는 window 속성으로 접근 가능
    -최상위 let, const는 var와 달리 window 속성으로 추가되지 않음

2장 새 창 열기 (2_새창열기(open).html)
    -window.open(URL, 창 이름, 옵션)으로 새 창 또는 탭 열기
    -옵션에 width, height, left, top 등 지정 가능
    -예제는 빈 창을 열고 반환된 참조를 child에 저장
    -child.document.write()로 열린 빈 창에 '새창' 제목 출력
    -팝업이 차단되면 null이 반환될 수 있어 if(child)로 확인
    -실제 창 형태와 크기 적용 여부는 브라우저 설정에 따라 달라질 수 있음

3장 창 이름과 target (3_윈도우이름지정.html)
    -open('','childWin',...)으로 이름이 childWin인 창 열기
    -같은 이름의 창이 있으면 해당 창을 재사용할 수 있음
    -링크의 target="childWin"으로 지정한 창에 링크 페이지 표시
    -클릭 시 openWin()을 호출하도록 이벤트 연결
    -소스의 <botton>은 <button>으로 수정 필요

4장 부모 창과 자식 창 (4_parent(small).html, 5_child(large).html)
    -작은 이미지에 마우스를 올리면 onmouseover로 openLarge() 실행
    -큰 이미지가 있는 5_child(large).html을 새 창으로 열기
    -작은 이미지에서 마우스가 벗어나면 onmouseout에서 child.close() 실행
    -자식 창도 setTimeout(()=>close(),5000)으로 약 5초 뒤 스스로 닫기
    -close()는 예제처럼 스크립트로 연 창을 닫는 데 사용
    -이미지 표시에는 ch09_img/small.jpg와 large.jpg 파일 필요
    -팝업 차단 시 child가 null일 수 있으므로 if(child && !child.closed)로 확인 후 닫기

5장 location으로 페이지 이동 (6_location.html)
    -location은 현재 페이지의 주소 정보를 다루는 객체
    -setInterval()로 1초마다 sec를 증가시키고 경과 문구 추가
    -약 5초 뒤 clearInterval()로 반복을 멈추고 7_history.html로 이동
    -location.href = '주소' 또는 location.assign('주소')로 페이지 이동
    -location = '주소' 형태도 사용 가능
    -이 예제의 이동은 방문 기록을 남겨 뒤로가기 가능
    -경과 문구의 닫는 태그에 >가 빠져 있으므로 </h${sec}>로 수정 필요

6장 history로 이전 페이지 이동 (7_history.html)
    -history는 현재 탭의 방문 기록을 이동하는 기능 제공
    -history.back(): 바로 이전 방문 기록으로 이동
    -history.go(-1): 한 단계 이전으로 이동하며 back()과 같은 의미
    -예제의 두 버튼은 동일한 뒤로가기 동작 수행
    -이전 방문 기록이 없으면 뒤로 이동하지 않음
