1장 문자열 내장 기능 (1_string내장함수.html)
    -length: 문자열 길이 확인, concat(): 문자열 연결
    -substring(a,b): 인덱스 a부터 b 직전까지 추출, substring(a): 끝까지 추출
    -substr(a,b): a부터 b개 추출하는 예제의 문법
    -indexOf(): 처음 발견된 위치, lastIndexOf(): 마지막 발견된 위치 반환
    -찾는 문자가 없으면 -1 반환, 인덱스는 0부터 시작
    -trim(): 앞뒤 공백 제거, 중간 공백은 유지
    -toUpperCase(), toLowerCase(): 대문자·소문자로 변환
    -replace('문자','새문자'): 첫 일치 부분 변경, replaceAll(): 모든 일치 부분 변경
    -replaceAll(' ',''): 일반 공백을 모두 제거
    -문자열 메소드는 원본을 직접 바꾸지 않으므로 결과를 유지하려면 재할당 필요

2장 정규표현식 기본 문법 (2_정규표현식.html)
    -/패턴/ 형태로 문자열의 규칙 표현
    -[0-9] 또는 \d: 숫자, [a-zA-Z]: 영문자, [가-힣]: 한글 완성형 음절
    -\w: 영문자·숫자·밑줄(_), \W: 그 외 문자
    -\D: 숫자가 아닌 문자, \s: 공백·탭·줄바꿈 등의 공백 문자
    -.: 기본적으로 줄바꿈을 제외한 문자 하나, \.: 마침표 자체
    -^와 $: 문자열 시작과 끝을 지정하여 전체 형식 검사
    -{n,}: n회 이상, {2,4}: 2~4회 반복
    -?: 0~1회, +: 1회 이상, *: 0회 이상 반복

3장 test()와 match() (2_정규표현식.html)
    -패턴.test(문자열): 일치하는 부분이 있으면 true, 없으면 false
    -문자열.match(패턴): 예제처럼 g 플래그가 없으면 일치 내용과 캡처 그룹을 배열로 반환
    -match()에서 일치하는 내용이 없으면 null 반환
    -'abcd@ef'는 영문 소문자·특수문자를 포함하고 숫자·한글·대문자는 포함하지 않음
    -이메일 예제에서 hong@hong.com은 통과, homn@hong.com@bbb는 실패
    -예제 이메일 패턴은 단순한 연습용으로 모든 유효한 이메일 형식을 처리하지는 않음

4장 회원가입 입력 검사 (3_quiz.html, 4_quiz강사님.html)
    -onsubmit="return joinCheck()"로 제출 시 검사 함수 실행
    -입력값의 value를 읽고 trim()으로 앞뒤 공백 제거
    -잘못된 값이면 alert()로 안내하고 focus()로 입력 위치 이동
    -return false로 폼 제출 중단
    -강사님 소스: 이름은 2자 이상이며 지정된 숫자·특수문자를 포함하면 실패
    -메일은 선택 입력, 입력한 경우에만 이메일 패턴 검사
    -비밀번호는 필수이며 확인값과 같아야 함
    -예제 비밀번호 조건: 영문자·숫자·특수문자를 포함한 4자 이상
    -비밀번호가 다르면 두 입력칸을 비우고 다시 입력하도록 처리

5장 3_quiz.html의 주요 오류
    -joinCheck 함수가 입력값을 읽은 직후 닫혀 검사문이 함수 밖에 있음
    -함수 밖의 return false는 문법 오류이므로 검사문을 함수 안으로 이동해야 함
    -HTML의 메일 입력 이름은 mail인데 JS에서는 frm.email로 접근하여 불일치
    -name, email, pw, pwChk는 let 또는 const로 선언 필요
    -비밀번호 포함 여부 검사 대상이 name으로 되어 있어 pw로 변경 필요
    -필수 문자가 없을 때 실패하도록 !patternNum.test(pw)처럼 부정 조건 사용
    -pw = pwChk는 대입이므로 불일치 비교에는 pw !== pwChk 사용

6장 강사님 소스 및 학습 시 주의점
    -frm 자동 참조 대신 document.forms['frm']으로 폼을 명시하면 의도가 분명함
    -메일 형식 오류와 비밀번호 조합 오류에서 이름 칸으로 focus되는 부분은 해당 입력칸으로 수정 필요
    -현재 이름 검사는 일부 문자를 금지하는 방식이라 내부 공백 등도 통과 가능
    -한글·영문만 허용하려면 선언된 /^[가-힣a-zA-Z]{2,}$/ 패턴으로 전체 검사
    -비밀번호에 trim()을 적용하면 앞뒤 공백을 제거한 값으로 비교하게 됨
    -검사를 모두 통과하면 함수가 undefined를 반환하며, 이 이벤트 처리에서는 제출을 막지 않음
    -action="#"인 연습 폼으로 실제 회원가입 저장 기능은 포함되어 있지 않음
