1장 익명함수와 화살표 함수 (01, 02)
    -함수 표현식: let fun = function(){...};처럼 함수를 변수에 저장
    -변수에 함수가 할당된 뒤 fun()으로 호출 가능
    -화살표 함수: (매개변수) => {실행문} 형태
    -매개변수가 하나면 괄호 생략 가능: i => i*i
    -본문이 하나의 식이면 중괄호와 return 생략 가능: (i,j) => i+j
    -let으로 선언한 함수 변수에는 다른 함수를 다시 할당할 수 있음

2장 선언적 함수와 호이스팅 (03)
    -function fun(){...} 형태로 이름을 붙여 함수 선언
    -예제처럼 같은 스크립트의 최상위 함수 선언은 선언문 앞에서도 호출 가능
    -같은 이름으로 두 번 선언한 예제에서는 마지막 선언이 적용됨
    -따라서 세 번의 fun() 호출 모두 '수정된 함수 fun' 출력

3장 기본 매개변수와 반환값 (04, 05)
    -매개변수는 함수가 전달받는 값을 담는 변수, 인자는 호출할 때 전달하는 값
    -function pow(x=5,y=3): 인자를 생략하거나 undefined를 전달하면 기본값 사용
    -04의 pow(5,3), pow(5), pow()는 모두 125 반환
    -return은 결과를 반환하고 함수 실행 종료, 반환값이 없으면 undefined
    -기본값 없이 생략한 매개변수는 undefined가 됨
    -초과 인자는 선언된 매개변수에 대응되지 않지만 arguments로 접근 가능
    -05는 반복 곱셈으로 거듭제곱 계산, pow(5,3)은 125
    -05의 pow(5), pow()는 반복 조건이 거짓이 되어 초기값 1을 반환

4장 가변 인자와 배열 생성 (06, 07)
    -가변 인자 함수: 전달받는 인자 개수가 달라도 처리하는 함수
    -일반 함수의 arguments에 전달된 인자가 들어가며 length로 개수 확인
    -Array(): 빈 배열, Array(1,2,'삼'): 전달한 값으로 배열 생성
    -Array(3): 길이가 3이고 요소가 비어 있는 배열 생성
    -직접 만든 array(): 인자 0개는 [], 1개는 그 수만큼 undefined 추가
    -인자 2개 이상이면 for-of와 push()로 인자를 배열에 저장
    -array(3)은 undefined가 실제로 들어 있어 빈 슬롯을 가진 Array(3)과 다름
    -화살표 함수에는 자체 arguments가 없지만 (...args)로 가변 인자 처리 가능

5장 가변 인자 합계와 외부 JS (08, sumAll.js)
    -<script src="sumAll.js"></script>로 외부 함수를 불러온 뒤 호출
    -sumAll(): 인자가 없으면 -999, 있으면 전달된 숫자들의 합 반환
    -arguments를 for-of문으로 순회하며 result에 누적
    -08의 화면 출력: -999, 4, 33
    -sumAll.js의 콘솔 출력: -999, 4, 34

6장 내부함수 (09)
    -함수 안에 함수를 정의하여 해당 범위에서 사용하고 이름 충돌 방지
    -pythagoras() 내부의 square는 한 수의 제곱 계산
    -Math.sqrt(square(width)+square(height))로 직각삼각형의 빗변 계산
    -pythagoras(3,4)는 5 반환
    -외부 square(3,4,5)는 제곱합을 비교하여 true 반환

7장 콜백함수 (10)
    -다른 함수에 인자로 전달되어 호출되는 함수
    -calltentimes(callback)는 for문으로 callback()을 10회 실행
    -익명함수와 화살표 함수를 각각 전달하므로 날짜와 시간이 총 20회 출력
    -이 예제의 콜백은 즉시 순서대로 실행되며, 콜백이 항상 비동기인 것은 아님

8장 setTimeout과 setInterval (11, 12)
    -setTimeout(함수, 밀리초): 지정한 지연 시간이 지난 뒤 한 번 실행 예약
    -setInterval(함수, 밀리초): 일정 간격으로 반복 실행 예약
    -1000ms는 1초, 반환된 타이머 ID로 타이머 관리
    -clearInterval(id): 반복 타이머 중지, clearTimeout(id): 일회성 예약 취소
    -11은 3초 뒤 문구 출력 예약 후 약 2초 동안 while문 실행
    -타이머는 진행 중인 동기 코드를 중단하지 않으므로 실제 실행이 늦어질 수 있음
    -12는 1초마다 시간을 갱신하고 약 10초 뒤 반복 종료
    -document.body.innerHTML로 본문을 바꾸고 +=로 문구 추가
