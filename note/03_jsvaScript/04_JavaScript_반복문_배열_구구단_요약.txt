1장 while문과 do-while문 (1_while_doWhile.js)
    -while문: 조건을 먼저 검사하고 참이면 반복 실행
    -do-while문: 코드를 먼저 실행하므로 최소 1회 실행
    -new Date().getTime(): 1970년 1월 1일 UTC부터 경과한 밀리초
    -시작 시간에 1000ms를 더해 약 1초 동안 반복하고 cnt++로 횟수 계산
    -console.log()로 실행 횟수 출력, 횟수는 실행 환경에 따라 달라짐

2장 배열과 반복 출력 (2_배열출력.html, no_02.html)
    -배열은 여러 값을 저장하며 인덱스는 0부터 시작
    -arr = [273, 32, '홍길동'], arr.length는 3
    -일반 for문: 인덱스를 증가시키며 arr[idx]에 접근
    -for-in문: 열거 가능한 속성 이름을 순회, 배열에서는 인덱스가 문자열로 전달됨
    -for-of문: 배열 등 반복 가능한 자료의 값을 직접 순회
    -일반 객체는 기본적으로 for-of문으로 직접 순회할 수 없음
    -forEach(function(data, idx){...}): 요소 값과 인덱스로 콜백 실행
    -화살표 함수: arr.forEach((data, idx) => {...}) 형태로 작성
    -배열 값 순회에는 for-of문이나 forEach()가 적합

3장 중첩 for문과 전체 구구단 (3_중복for문.html, no_01.html, no_03.html)
    -반복문 안에 반복문을 넣어 행과 열을 생성
    -제목 반복문: 2단부터 9단까지 <th>로 출력
    -바깥 반복문: 곱하는 수 i를 1~9까지 변경하며 행 생성
    -안쪽 반복문: 단 j를 2~9까지 변경하며 j * i 결과를 셀에 출력
    -<table>은 표, <tr>은 행, <th>는 제목 셀, <td>는 데이터 셀
    -no_01.html과 no_03.html은 같은 구구단 표 소스

4장 입력값 검사와 특정 구구단 (4_특정구구단출력.html, no_04.html)
    -prompt()로 원하는 단을 입력받고 parseInt()로 정수 변환
    -do-while문으로 먼저 입력받은 후 잘못된 값이면 다시 입력
    -isNaN(su) || su<2 || su>9: 숫자로 변환되지 않거나 2~9 범위 밖인지 검사
    -정상 입력이면 for문으로 해당 단의 1~9 곱셈 결과 출력
    -parseInt()는 '2abc'나 '2.5'도 2로 처리하므로 엄격한 정수 검사는 아님
    -취소도 재입력 대상이므로 종료하려면 별도의 취소 처리가 필요

5장 출력과 표 스타일
    -document.write(): HTML 문자열을 문서에 출력
    -템플릿 리터럴: 백틱과 ${변수 또는 식}을 사용해 문자열에 값 삽입
    -width:800px와 margin:0 auto로 표 너비 지정 및 가운데 배치
    -border-collapse:collapse로 셀 테두리를 합침
    -text-align:center와 border로 셀 내용 정렬 및 테두리 지정

6장 소스에서 주의할 부분
    -3_중복for문.html의 제목 행 끝 </th>는 </tr>로 수정 필요
    -여러 구구단 소스의 for(i=...)와 for(j=...)는 let으로 변수 선언 필요
    -선언하지 않은 변수 대입은 일반 모드에서 전역 변수를 만들 수 있고 엄격 모드에서는 오류 발생
    -no_04.html의 결과 표시 기호 '-'는 곱셈 결과를 나타내는 '='로 수정 필요
    -2_배열출력.html의 마지막 두 화살표 함수 예제와 제목 번호 7이 중복됨
