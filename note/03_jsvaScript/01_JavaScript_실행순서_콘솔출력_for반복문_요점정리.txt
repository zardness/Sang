JavaScript 실행 순서 · 콘솔 출력 · for 반복문 요점 정리
대상: 1_firstEx(1).html, 2(3).js, 2_consol(1).html

1장 script와 실행 순서 (1_firstEx)
    -<script> 안에 JavaScript 코드를 작성한다.
    -이 예제의 일반 script는 문서를 읽는 도중 만나는 순서대로 실행된다.
    -HTML에 직접 작성한 제목과 document.write()로 작성한 제목이 차례로 나타난다.
    -의도한 순서: 첫번째 → 두번째 → 세번째 → 네번째 → 다섯번째 → 여섯번째 → 일곱번째 메시지.
    -// 내용: 한 줄 주석. /* 내용 */: 여러 줄 주석.
    -document.write('문자열'): 문자열을 HTML 문서에 작성한다.
      문자열 속 <h2> 같은 태그도 HTML로 해석한다.
    -실제 코드의 '<h2>첫번째 메세지<h2>'는 닫는 태그가 빠져 있다.
      '<h2>첫번째 메세지</h2>'처럼 맞춰야 한다.
    -세번째·다섯번째·일곱번째 메시지도 h2와 h3가 섞여 있어 </h2>로 정리한다.
    -마지막 script가 </html> 뒤에 있다. 문서 구조에 맞게 body 안으로 옮긴다.
    -document.write()는 문서 로딩 후 호출하면 기존 문서를 덮어쓸 수 있다.
      일반적인 화면 갱신에는 요소를 찾아 textContent 등을 사용하는 방법이 적합하다.

2장 외부 JavaScript 연결 (2_consol)
    -<script src="2.js"></script>: 외부 JavaScript 파일을 불러와 실행한다.
    -현재 첨부 파일명은 2(3).js이므로 그대로 사용하려면 src="2(3).js"로 수정한다.
      또는 JavaScript 파일명을 2.js로 변경해 HTML과 같은 폴더에 둔다.
    -외부 script가 실행된 뒤 다음 내부 script에서 i와 sum을 사용한다.
    -파일 경로가 틀려 외부 파일을 읽지 못하면 변수가 정의되지 않아 오류가 발생한다.
    -이 예제는 module, async, defer 설정이 없는 일반 script 연결 방식이다.

3장 변수 선언의 의미 (2(3).js)
    -let sum = 0;: 누적 합계를 저장할 변수를 0으로 초기화한다.
    -var: 함수 스코프를 가진다. 함수 밖에서 선언하면 전역 범위가 될 수 있다.
    -let: 블록 스코프를 가지며 값을 다시 대입할 수 있다.
    -const: 블록 스코프를 가지며 선언한 변수에 다른 값을 다시 대입할 수 없다.
      객체·배열을 담은 경우 내부 내용까지 자동으로 불변이 되는 것은 아니다.
    -원문 주석의 'var=전역변수, let=지역변수'는 정확한 구분이 아니다.
      선언한 위치와 함수·블록 범위를 함께 확인해야 한다.
    -이 예제의 sum은 최상위 let이므로 뒤의 일반 script에서도 접근할 수 있다.

4장 for 반복문과 누적 합계
    -기본 구조: for (초기화; 반복 조건; 증감) { 실행할 코드 }
    -for (var i = 1; i <= 5; i++)는 i가 1부터 5일 때까지 반복한다.
    -i++: i를 1 증가시킨다.
    -sum += i;는 sum = sum + i;와 같다.
    -실행 과정:
      i=1 → sum=1
      i=2 → sum=3
      i=3 → sum=6
      i=4 → sum=10
      i=5 → sum=15
    -마지막 반복 후 i가 6이 되고 i <= 5가 거짓이 되어 종료한다.
    -최종 값은 sum=15, i=6이다.
    -i를 var로 선언했으므로 for 블록 밖에서도 접근할 수 있다.
      for (let i = 1; ...)로 바꾸면 반복문 밖에서 해당 i에 접근할 수 없다.

5장 console.log와 화면 출력
    -console.log(): 개발자 도구의 Console에 값을 출력한다.
    -반복문 안에서는 i와 현재 누적 합계를 출력하고, 종료 후 안내 문구와 i=6을 출력한다.
    -쉼표로 여러 값을 전달할 수 있다.
      console.log('i=', i, '일때까지 누적된합은', sum);
    -문자열과 숫자를 +로 연결하면 숫자가 문자열로 변환되어 이어 붙는다.
    -브라우저에서 F12 → Console을 열어 로그를 확인할 수 있다.
    -document.write(): 웹페이지에 출력한다. console.log()와 출력 위치가 다르다.

6장 최종 출력 문구의 오류
    -현재 코드: document.write(i + '까지 누적된 최종합은' + sum);
    -경로를 맞춰 정상 실행하면 '6까지 누적된 최종합은15'라고 표시된다.
    -실제로 더한 범위는 1~5이므로 반복 종료 후 i=6을 그대로 표시하면 설명이 틀린다.
    -간단한 수정 예:
      document.write('5까지 누적된 최종합은 ' + sum);
    -범위를 변경할 수 있게 작성하려면 종료값을 별도 변수로 관리한다.
      const end = 5;
      let sum = 0;
      for (let i = 1; i <= end; i++) {
          sum += i;
      }
      console.log(end + '까지 누적된 최종합은 ' + sum);
    -위 수정 예는 기존 누적 코드와 교체하여 사용한다.

핵심 정리
    -script는 이 예제에서 작성 순서대로 실행된다.
    -console.log는 콘솔 출력, document.write는 HTML 문서 출력이다.
    -for 반복문은 초기화 → 조건 검사 → 본문 → 증감 순으로 동작한다.
    -1부터 5까지 합은 15이며, 원본 코드의 반복 종료 후 i는 6이다.
    -외부 파일명과 src 경로, 변수 범위, HTML 닫는 태그를 확인한다.
