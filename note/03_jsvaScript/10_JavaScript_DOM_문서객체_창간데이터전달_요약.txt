1장 문서 객체 생성 (1_문서객체생성.html)
    -DOM은 HTML 요소를 객체로 다루는 구조
    -window.onload에 함수를 등록하여 문서와 리소스 로드 후 작업
    -document.createElement('h1'): 요소 생성
    -document.createTextNode('내용'): 텍스트 노드 생성
    -appendChild(): 부모 요소에 자식 노드 추가
    -setAttribute('src','경로'), setAttribute('alt','설명'): 속성 설정
    -innerHTML로 HTML 문자열을 넣어 내용 변경 가능
    -소스의 textNote와 textNode 이름이 달라 오류 발생: 같은 이름으로 수정 필요
    -이 오류 때문에 뒤에 있는 이미지 생성과 HTML 추가도 실행되지 않음

2장 id로 요소 선택 및 시계 제어 (id이용 소스)
    -getElementById('id'): 해당 요소 하나 반환, 없으면 null
    -clock.innerHTML에 현재 날짜와 시간을 표시
    -setInterval()로 1초마다 갱신하고 clearInterval()로 중지
    -timerToggle을 1과 0으로 바꾸어 실행·중지 상태 관리
    -버튼 클릭 시 타이머, 버튼 문구, 시계 색상을 함께 변경
    -style.backgroundColor와 style.color로 배경색·글자색 지정

3장 class와 name으로 요소 선택 (class이용, name이용 소스)
    -getElementsByClassName('클래스'): 일치하는 요소들을 HTMLCollection으로 반환
    -getElementsByName('이름'): 같은 name을 가진 요소들을 NodeList로 반환
    -둘 다 배열 자체는 아니지만 [0], [1], length로 접근 가능
    -일반 요소 내용은 innerHTML, 입력 상자의 값은 value로 처리
    -라디오 버튼의 선택 여부는 checked로 확인
    -로그인 예제는 아이디·비밀번호·성별을 검사하고 빈 입력칸에 focus()
    -로그인 검사 끝에 항상 return false가 있어 정상 입력이어도 제출하지 않음
    -class 소스의 var clock2.value = ...는 문법 오류: var clock2 = ...로 수정 필요

4장 선택자와 문서 객체 제거 (3_문서객체제거하기.html)
    -querySelector('선택자'): 첫 요소 반환, 없으면 null
    -querySelectorAll('선택자'): 일치하는 요소의 NodeList 반환, 없으면 길이 0
    -getElementsByTagName('h1'): 해당 태그들의 HTMLCollection 반환
    -부모.removeChild(자식): 그 부모의 직접 자식 노드 제거
    -예제 의도는 버튼으로 h1을 추가하고 하나씩 제거하는 것
    -remove 이름을 function과 const로 중복 선언하여 현재는 문법 오류 발생
    -추가 버튼이 호출하는 append()가 없으므로 추가 함수 이름도 수정 필요
    -기존 h1은 #wrap 안에 있어 document.body.removeChild(h1[0])로 제거할 수 없음
    -h1[0].remove() 또는 h1[0].parentNode.removeChild(h1[0])로 제거 가능

5장 부모·자식 창의 데이터 전달 (4_parent.html, 4_child.html)
    -부모 창에서 이름과 날짜를 입력하고 자식 창을 여는 실습
    -자식 창의 opener는 자신을 연 창을 참조
    -opener.document.getElementById(...).value로 부모 입력값 읽기
    -자식 창에서 이름을 수정하고 인사·재무·총무·개발 중 파트 선택
    -sendData(part)가 부모의 파트 표시와 이름 입력값을 변경한 뒤 창 닫기
    -이 방식의 직접 DOM 접근은 두 창이 같은 출처이고 opener가 존재해야 가능
    -부모 소스는 open() 반환값을 저장하지 않고 child를 검사하여 오류 발생
    -const child = open(...)처럼 반환값을 저장한 뒤 팝업 차단 여부 검사 필요

6장 아이디 중복 확인 화면 (5_join.html, 5_confirm.htm)
    -5_join.html은 아이디 입력칸과 중복확인 버튼을 만든 미완성 예제
    -버튼에서 호출하는 openConfirm()이 정의되어 있지 않음
    -스크립트가 찾는 #insa 요소가 없어 onclick을 설정할 때 오류 발생
    -open() 반환값을 저장하지 않은 채 child를 검사하는 문제도 있음
    -열려는 5_confirm.html과 첨부 파일 5_confirm.htm의 확장자가 다름
    -5_confirm.htm은 기본 HTML 틀만 있고 중복 확인 기능은 구현되지 않음

7장 DOM 사용 시 구분할 점
    -텍스트만 표시할 때는 textContent, HTML 구조를 넣을 때는 innerHTML 사용
    -innerHTML +=는 기존 자식 요소도 다시 만들 수 있어 기존 이벤트 연결에 주의
    -요소 선택 결과가 null이거나 목록이 비어 있는지 확인 후 접근
    -이번 소스에는 오타와 미완성 부분이 있어 의도한 동작과 실제 실행 상태를 구분해야 함
