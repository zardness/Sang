1장 생성자 함수 (1_생성자함수.html)
    -같은 구조의 객체를 여러 개 만들 때 사용하는 함수
    -function Student(name,kor,mat,eng){...} 형태로 정의
    -new Student(...)로 객체를 생성하고 this에 이름과 점수 저장
    -new로 호출할 때 this는 새로 생성하는 객체를 가리킴
    -getSum(): 국어·수학·영어 총점, getAvg(): 평균을 정수로 반올림
    -toString(): 학생 정보와 총점·평균을 문자열로 반환
    -객체 5개를 배열에 넣고 forEach로 출력
    -생성자 안에서 this.getSum = function(){...}처럼 정의하면 객체마다 별도 함수 생성

2장 prototype으로 메소드 공유 (2_prototype을이용한생성자함수.html)
    -생성자 함수에서는 이름과 점수 등 객체별 데이터만 초기화
    -Student.prototype.getSum = function(){...}으로 공통 메소드 등록
    -생성된 객체들은 같은 prototype의 메소드를 공유
    -객체마다 같은 기능의 함수를 새로 만드는 중복을 줄임
    -객체에 없는 메소드는 연결된 prototype에서 찾아 실행
    -이 소스처럼 직접 대입한 prototype 메소드는 열거 가능하므로 for-in에도 포함됨

3장 class와 constructor (3_class.js)
    -class Student {...}로 속성과 메소드를 묶어 표현
    -constructor(name,kor,mat,eng)는 new Student(...) 실행 시 속성 초기화
    -getSum(){...}, getAvg(){...}처럼 메소드 정의
    -클래스의 일반 인스턴스 메소드는 prototype에 정의되어 객체들이 공유
    -클래스 문법으로 정의한 메소드는 for-in 순회에 포함되지 않음
    -예제 홍길동의 점수 99, 100, 86 → 총점 285, 평균 95

4장 문자열 변환과 외부 파일 연결 (3_class.html, 3_class.js)
    -<script src="3_class.js"></script>로 외부 JS 파일 실행
    -document.write(hong)은 객체를 문자열로 바꾸며 toString() 결과 출력
    -템플릿 리터럴 `${hong}`도 문자열 변환 시 toString() 사용
    -console.log(hong)은 객체 자체를 콘솔에 전달하므로 문자열 출력과 다름
    -3_class.js는 document.write()를 사용하므로 브라우저 문서 환경에서 실행

5장 세 방식의 차이와 주의점
    -생성자 내부 메소드: 객체마다 함수를 별도로 가짐
    -prototype 메소드: 생성자 밖에 정의하고 여러 객체가 공유
    -class: 생성자와 공유 메소드를 하나의 클래스 문법으로 정리
    -이번 소스의 Math.round(총점/3)는 소수 첫째 자리에서 반올림하여 정수 반환
    -1·2번의 for-in은 메소드 이름까지 순회하므로 조건문으로 출력 대상을 구분
    -class 소스는 toString()에서 속성과 계산 결과를 직접 연결하여 문자열 생성
