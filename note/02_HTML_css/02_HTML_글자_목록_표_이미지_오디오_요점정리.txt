HTML 기본 태그 요점 정리
대상: 기본 예제, 글자, 목록, 표 2개, 이미지, 오디오 예제 총 7개

1장 기본 구조와 이미지 링크 (0_기본예제)
    -<!DOCTYPE html>: HTML5 문서 선언.
    -head: 문자 인코딩, 제목, CSS 등 설정 정보를 작성한다.
    -body: 화면에 표시할 내용을 작성한다.
    -<meta charset="utf-8">: 문자 인코딩 설정.
    -태그는 요소의 종류, 속성은 추가 설정, 속성값은 설정 내용을 뜻한다.
    -대부분 여는 태그와 닫는 태그를 사용하지만 img, meta 등은 닫는 태그가 없다.
    -body { background-color: #c73b3b; }: 본문 배경색 설정.
    -<a href="주소">: 해당 주소로 이동하는 링크.
    -a 안에 img를 넣으면 이미지를 클릭했을 때 링크로 이동한다.
    -예제는 ch02_img/sulhyun.jpg 이미지를 클릭하면 다음 사이트로 이동한다.

2장 글자 관련 태그 (1_글자관련태그)
    -h1~h6: 제목의 중요도와 계층을 나타낸다. 숫자가 작을수록 상위 제목이다.
    -h7은 표준 제목 태그가 아니다. 내용은 표시될 수 있지만 제목 의미는 없다.
    -p: 문단을 구분한다. 기본 스타일에서는 문단 사이에 여백이 생긴다.
    -&lt;와 &gt;: 각각 <와 > 문자를 표시한다. &lt;WEB&gt;는 <WEB>로 보인다.
    -i: 다른 어조나 용어 등을 구분하며, 기본적으로 기울임꼴로 표시된다.
    -b: 주의를 끌 글자를 표시하며, 기본적으로 굵게 표시된다.
    -strong: 중요한 내용을 의미하며, 기본적으로 굵게 표시된다.
    -sup / sub: 윗첨자 / 아랫첨자.
    -ins / del: 삽입된 내용 / 삭제된 내용. 기본적으로 밑줄 / 취소선으로 표시된다.
    -span: 문장 일부를 묶어 스타일을 적용할 때 사용한다.
    -span { color: red; }: span 내부 글자를 빨간색으로 표시한다.
    -가격 예제: 기존 가격은 del, 할인 가격은 b, 할인율은 span으로 강조한다.
    -id="top"으로 위치를 지정하고 <a href="#top">으로 해당 위치에 이동한다.

3장 목록 태그 (2_목록태그)
    -ul: 순서가 없는 목록. li: 각 목록 항목.
    -ol: 순서가 있는 목록. 내부 항목은 동일하게 li를 사용한다.
    -예제의 ul type="circle": 속이 빈 원 모양의 목록 표시.
    -ul의 type 속성 대신 CSS list-style-type으로 표시 모양을 지정하는 것이 적절하다.
    -표시 모양 예: disc(채운 원), circle(빈 원), square(사각형).
    -ol type="i": 소문자 로마 숫자 i, ii, iii로 순서를 표시한다.
    -ol의 type 값: 1, a, A, i, I. 소스 주석의 마지막 l은 대문자 I로 고친다.

4장 표 기본 구조와 병합 (3_표태그1)
    -table: 표 전체. caption: 표 제목. tr: 한 행.
    -td: 일반 데이터 셀. th: 제목 셀.
    -첫 번째 표는 3행 4열이며 셀 병합이 없다.
    -colspan="3": 한 셀이 가로 방향으로 3개 열을 차지한다.
    -rowspan="2": 한 셀이 세로 방향으로 2개 행을 차지한다.
    -병합으로 차지한 영역에는 셀을 중복해서 만들지 않는다.
    -두 번째 표는 첫 행의 2~4열을 병합하고, 2~3행의 3열을 병합한다.
    -table 배경은 검정, tr 배경은 흰색으로 지정한다.
    -margin: 10px 20px; → 바깥 여백: 위·아래 10px, 좌·우 20px.
    -padding: 5px 10px; → 셀 안쪽 여백: 위·아래 5px, 좌·우 10px.
    -여백 값이 4개일 때의 순서: 위 → 오른쪽 → 아래 → 왼쪽.
    -text-align: center; → 셀 안의 글자를 가로 가운데 정렬한다.
    -예제의 padding과 text-align은 td 선택자에만 지정되어 있다.

5장 성적표 구성 (3_표태그2)
    -table ex1: 국어·영어·수학의 제목 행과 점수 행을 작성한다.
    -점수는 100, 60, 80이며 평균은 80이다.
    -table ex2: 평균 행을 추가하고 평균값 셀에 colspan="2"를 적용한다.
    -table ex3: '중간고사성적' 셀이 rowspan="3"으로 세 행을 차지한다.
    -마지막 행의 '평균' 셀은 colspan="2"로 두 열을 차지한다.
    -평균 80은 HTML에 직접 작성된 값이며 자동 계산된 결과가 아니다.
    -표 배경은 빨강, 행 배경은 노랑으로 지정되어 있다.
    -소스에 body 시작 태그가 반복되어 있다. 하나의 body 안에 표 3개를 배치한다.

6장 이미지 태그 (4_이미지태그)
    -<img src="경로" alt="설명">: 이미지 삽입.
    -src: 이미지 파일 위치. 상대 경로 또는 외부 URL을 사용할 수 있다.
    -ch02_img/sulhyun.jpg: HTML 파일 기준 하위 폴더의 이미지 경로.
    -alt: 이미지의 대체 설명. 이미지 로딩 실패와 화면 읽기 도구 등에 활용된다.
    -별도 크기 제한이 없으면 이미지의 기본 크기로 표시한다.
    -width="100": 너비를 100px로 지정한다.
    -height="100": 높이를 100px로 지정한다.
    -너비나 높이 하나만 지정하면 일반적으로 원래 비율을 유지한다.
    -너비와 높이를 모두 지정하면 원래 비율과 달라 이미지가 변형될 수 있다.
    -hr: 내용의 주제 전환을 나타내며, 기본적으로 가로선으로 표시된다.
    -hr의 color 같은 표현용 속성 대신 CSS로 색상과 테두리를 지정한다.
    -CSS에서 빨간색은 red 또는 #ff0000 등으로 표현한다.

7장 오디오 태그 (5_오디오태그)
    -audio: 웹페이지에 음성이나 음악을 삽입한다.
    -src: 오디오 파일 경로.
    -controls: 재생·일시정지·음량 등 조작 기능을 표시한다.
    -preload="auto": 브라우저에 미리 로드할 수 있음을 알린다. 자동 재생 설정은 아니다.
    -실제 미리 로드 범위는 브라우저와 네트워크 상황 등에 따라 달라질 수 있다.
    -loop: 재생이 끝나면 반복한다.
    -source: audio 내부에서 재생할 파일을 지정한다.
    -첫 번째 예제는 audio의 src로 stevejobs1.mp3를 연결한다.
    -두 번째 예제는 source로 stevejobs2.mp3를 연결하고 반복 재생을 설정한다.
    -controls="controls"와 loop="loop"는 각각 controls, loop로 줄여 쓸 수 있다.

8장 파일 실행 전 확인
    -이미지와 음성 파일은 HTML에 적힌 폴더명·파일명과 일치해야 한다.
    -이번 첨부에는 HTML만 있어 이미지·음성 파일 자체의 내용은 확인하지 않았다.
    -외부 이미지 주소는 네트워크 접근과 해당 서버의 제공 여부에 영향을 받는다.
    -한국어 중심 문서는 lang="ko"로 지정하고 빈 title에는 문서 제목을 작성한다.
    -핵심 구분: 글자(h1~h6, p) / 목록(ul, ol, li) / 표(table, tr, td, th)
      / 이미지(img) / 오디오(audio, source) / 링크(a).
