1장 HTML 기본 구조
    -<!DOCTYPE html> : HTML5 문서 선언
    -<head> : 설정 정보 / <body> : 화면에 표시할 내용
    -<meta charset="utf-8"> : 문자 인코딩 설정
    -<title> : 브라우저 탭 제목 / <!-- 내용 --> : 주석

2장 글자 관련 태그
    -<h1>~<h6> : 제목 수준 지정 / <h7>은 표준 제목 태그가 아님
    -<p> : 단락 / <br> : 줄바꿈 / <hr> : 주제 구분선
    -<i> : 기본적으로 기울임꼴 / <b> : 기본적으로 굵은 글씨
    -<strong> : 중요한 내용 표시, 기본적으로 굵게 출력
    -<sup> : 윗첨자 / <sub> : 아랫첨자
    -<ins> : 삽입된 내용, 기본 밑줄 / <del> : 삭제된 내용, 기본 취소선
    -<span> : 글자 일부를 묶어 색상 등의 스타일 적용
    -&lt; : < 표시 / &gt; : > 표시

3장 링크와 목록 태그
    -<a href="주소">내용</a> : 클릭하면 해당 주소로 이동
    -<a> 안에 <img> 작성 : 이미지를 클릭하여 이동
    -id="top" / href="#top" : 문서 안의 해당 위치로 이동
    -<ul> : 순서 없는 목록 / <ol> : 순서 있는 목록
    -<li> : 목록의 개별 항목
    -<ol type="i"> : 소문자 로마 숫자 / type 종류 : 1, a, A, i, I
    -목록 기호는 CSS list-style-type: circle; 등으로 지정

4장 표 태그
    -<table> : 표 / <caption> : 표 제목
    -<tr> : 행 / <td> : 데이터 셀 / <th> : 제목 셀
    -colspan="3" : 가로 방향으로 3개 열 병합
    -rowspan="2" : 세로 방향으로 2개 행 병합
    -병합한 영역에는 중복되는 셀을 추가하지 않음

5장 이미지 태그
    -<img src="경로" alt="설명"> : 이미지 표시
    -src : 이미지 파일 경로 또는 URL / alt : 대체 텍스트
    -width : 너비 / height : 높이
    -너비 또는 높이만 지정하면 일반적으로 원본 비율 유지
    -너비와 높이를 모두 지정하면 원본 비율과 달라질 수 있음
    -ch02_img/파일명.jpg : 현재 HTML 기준 하위 폴더의 이미지

6장 오디오 태그
    -<audio src="경로" controls></audio> : 오디오와 재생 조작 도구 표시
    -<source src="경로"> : audio 내부에서 오디오 파일 지정
    -controls : 재생·정지·음량 조절 / loop : 반복 재생
    -preload="auto" : 미리 불러오도록 브라우저에 요청, 자동 재생은 아님

7장 CSS 기본 설정
    -background-color : 배경색 / color : 글자색
    -#000000 : 검정 / #ffffff : 흰색 / #ff0000 : 빨강
    -margin: 10px 20px; : 바깥 여백, 위아래 10px·좌우 20px
    -padding: 5px 10px; : 안쪽 여백, 위아래 5px·좌우 10px
    -여백 값을 4개 쓰면 위 → 오른쪽 → 아래 → 왼쪽 순서
    -text-align: center; : 글자 가운데 정렬
