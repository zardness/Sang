HTML · CSS · JavaScript 기초 요점 정리
대상: 1(1).html, 2(1).html, 2(1).css, 2(2).js

1장 웹페이지의 구성
    -HTML: 웹페이지의 구조와 내용을 작성한다.
    -CSS: 배경색, 글자 크기 등 화면 디자인을 설정한다.
    -JavaScript: 입력창, 조건 판단 등 동적인 기능을 처리한다.
    -1(1).html은 HTML 안에 CSS와 JavaScript를 함께 작성한 예제다.
    -2(1).html은 CSS와 JavaScript를 외부 파일로 분리한 예제다.

2장 HTML 기본 구조
    -<!DOCTYPE html>: HTML5 문서임을 선언한다.
    -<html>: 문서 전체를 감싸는 최상위 요소다.
    -<head>: 문자 인코딩, 제목, 스타일과 스크립트 연결 정보를 작성한다.
    -<meta charset="utf-8">: 한글 등을 표현할 문자 인코딩을 설정한다.
    -<title>: 브라우저 탭에 표시할 제목을 설정한다. 예제 제목은 '첫예제'다.
    -<body>: 웹페이지에 표시할 내용을 작성한다.
    -<br>: 줄을 바꾼다. 예제의 <br />도 줄바꿈 용도다.
    -&nbsp;: 줄바꿈되지 않는 공백 문자이며, 예제에서는 글자 사이 간격을 넣는다.
    -<!-- 내용 -->: HTML 주석이다.
    -예제는 lang="en"이지만, 한국어 중심 문서에는 lang="ko"가 적절하다.

3장 CSS로 디자인 설정
    -body 선택자: 문서 본문에 스타일을 적용한다.
    -background-color: yellow; → 배경색을 노란색으로 설정한다.
    -font-size: 30pt; → 글자 크기를 30포인트로 설정한다.
    -내부 CSS: HTML의 <style> 태그 안에 작성한다.
    -외부 CSS: 별도 .css 파일에 작성하고 <link> 태그로 연결한다.
    -연결 예: <link href="2.css" rel="stylesheet" />
    -/* 내용 */: CSS 주석이다.

4장 JavaScript 입력과 출력
    -prompt("이름은?", "홍길동"): 이름 입력창을 표시하고 기본값을 제공한다.
    -확인을 누르면 입력 문자열, 취소를 누르면 실제 null 값을 반환한다.
    -if: 조건을 만족할 때만 중괄호 안의 코드를 실행한다.
    -!=: 두 값이 다른지 비교한다. &&: 두 조건을 모두 만족하는지 검사한다.
    -예제의 의도는 취소하거나 빈 문자열을 입력하면 인사말을 출력하지 않는 것이다.
    -문자열 + 문자열: 입력한 이름과 인사말을 이어 붙인다.
    -document.write(): HTML 문서에 문자열을 작성한다.
    -예제 출력: 홍길동님 방가방가 + 줄바꿈 두 번.
    -// 내용: 한 줄 주석. /* 내용 */: 여러 줄 주석.
    -내부 JavaScript는 <script> 안에 작성한다.
    -외부 JavaScript는 <script src="2.js"></script>로 연결한다.

5장 실행 흐름과 주의점
    -문서 로딩 중 head의 스크립트를 실행하여 이름을 입력받는다.
    -조건에 따라 인사말을 작성한 뒤 body의 안내 문구가 이어진다.
    -외부 파일로 분리하면 구조, 디자인, 동작을 각각 수정하기 쉽다.
    -첨부된 2(1).html은 '2.css', '2.js'를 참조하지만 첨부 파일명은 다르다.
    -첨부 파일명 그대로 실행하려면 href="2(1).css", src="2(2).js"로 맞춘다.
      또는 파일명을 각각 2.css, 2.js로 바꿔 HTML과 같은 폴더에 둔다.
    -문자열 'null'과 실제 null은 다르다. 취소 여부는 실제 null과 비교한다.
    -name을 선언 없이 사용하면 브라우저의 window.name과 충돌할 수 있다.
      별도 변수 userName을 const 또는 let으로 선언하는 편이 명확하다.
    -조건 수정 예:
      const userName = prompt("이름은?", "홍길동");
      if (userName !== null && userName.trim() !== "") {
          // 이름이 입력된 경우에 처리
      }
    -document.write()는 입력값을 HTML로 해석하고, 로딩 후 사용하면 문서를
      덮어쓸 수 있다. 일반적인 화면 갱신은 요소의 textContent 등을 사용한다.

핵심 정리
    -HTML = 구조 / CSS = 디자인 / JavaScript = 동작.
    -내부 작성 방식과 외부 파일 연결 방식을 구분한다.
    -외부 파일 경로, null 비교, 변수 선언을 확인한다.
