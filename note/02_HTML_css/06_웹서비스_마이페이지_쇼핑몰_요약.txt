1장 파일 구성
    -박상혁_웹서비스개발.html·css : 마이페이지 개인정보 변경 화면과 스타일
    -0803.html·css : 마이페이지 구조와 기본 스타일을 작성한 연습 파일
    -ex_01.html : 표를 이용한 개인정보 입력 화면, 일부 미완성
    -shoppingmall.html : 쇼핑몰 메인 화면의 영역 구성

2장 마이페이지 화면 구조
    -#wrap : 페이지 전체 / #nav_left·#nav_right : 좌우 상단 메뉴
    -#title : 마이페이지 제목 / #content : 본문 영역
    -#lnb : 나의여행·참여여행·관심여행·정보변경 메뉴
    -#my_content : 개인정보 변경 영역 / #sub_title : 소제목
    -#modify : 개인정보 입력 폼 / #footer : 하단 정보

3장 개인정보 입력 양식
    -<form> : 입력 양식 / <label for="id"> : 설명과 입력창 연결
    -type="text" : 이름·아이디·주소 / email : 이메일
    -type="tel" : 전화번호 / date : 생년월일
    -id : 요소 식별 / name : 제출할 항목 이름
    -.form_row : 항목별 행 / .button_box : 저장 버튼 영역
    -<button type="submit"> : 폼 제출 버튼
    -실제 개인정보 저장을 처리하는 서버 코드는 첨부 소스에 없음

4장 외부 CSS와 기본 스타일
    -<link href="파일.css" rel="stylesheet"> : 외부 CSS 연결
    -* {margin:0; padding:0;} : 기본 여백 초기화
    -list-style:none; : 목록 기호 제거
    -text-decoration:none; : 링크 밑줄 제거
    -display:block; : 링크를 블록으로 표시
    -width:1000px; margin:20px auto; : 고정 너비, 좌우 중앙 배치

5장 메뉴와 영역 디자인
    -float:left / right : 메뉴를 왼쪽·오른쪽으로 띄워 배치
    -overflow:hidden; : 넘친 내용 숨김, 예제에서는 float 영역을 감싸는 데도 사용
    -border : 테두리 / padding : 안쪽 여백 / margin : 바깥 여백
    -line-height : 줄 높이 / text-align:center : 글자 가운데 정렬
    -후손 선택자 : #content #my_content처럼 내부 요소 선택
    -속성 선택자 : input[type='email']처럼 입력 종류별 선택
    -class="active"는 선택 메뉴 표시용 이름이며, 해당 CSS는 아직 없음

6장 쇼핑몰 화면 구성
    -header : 상단 메뉴·로고·인기 메뉴·카테고리 메뉴
    -.gnb : 로그인·회원가입·장바구니 등의 공통 메뉴
    -.lnb : 상품 카테고리 메뉴
    -.section1 : 슬라이드 배너·사이드 배너 영역
    -.section2 : 인기 상품·MD 추천 상품 목록
    -footer : 회사 로고·주소·쇼핑 안내·저작권 정보
    -Pacifico 웹폰트 스타일시트 연결 / 실제 글꼴 적용은 CSS에서 지정
    -연결된 css/shoppingmall.css는 이번 첨부에 없어 스타일 내용은 확인 불가
    -상품·배너는 자리 표시용 내용이며 슬라이드·장바구니 동작은 구현되지 않음

7장 주요 수정 사항
    -박상혁_웹서비스개발.html : 중복 </head>, 불필요한 > 제거, wrap 닫는 </div> 추가
    -0803.html : 0803.css 연결 누락 / label의 for와 입력창 id 불일치 수정
    -0803.html : '저장'은 div이므로 제출하려면 실제 버튼으로 변경
    -0803.html : 불필요한 닫는 </div> 정리
    -ex_01.html : rel="stylesheeet" → rel="stylesheet", 미완성 < 구문 정리
    -CSS : width:85; → width:85px; / #mt_content → #my_content
    -CSS : padding:2px; 10px; → padding:2px 10px;
    -로고 선택자 : .logo #nav_left ... 대신 #nav_left .logo 등 실제 구조에 맞게 수정
    -주 HTML의 title은 content 밖에 있으므로 #content #title 선택자가 적용되지 않음
    -주 HTML의 폼은 div 구조이므로 table을 전제로 한 입력창 CSS가 적용되지 않음
    -#my_content의 height:30px는 폼 전체를 담기에 부족하므로 높이 설정 조정
    -ex_01.html의 #contents와 CSS의 #content 이름 일치 필요
    -쇼핑몰의 md_propduct 등 클래스 철자는 연결할 CSS와 일치시켜야 함
