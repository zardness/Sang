1장 form 태그 기본
    -<form> : 사용자가 입력한 데이터를 전송하는 영역
    -action : 전송할 주소 / method : 전송 방식, 생략하면 get
    -get : URL에 입력값 포함 / post : 요청 본문에 입력값 포함
    -name : 전송할 항목 이름 / value : 입력값 또는 버튼 표시 글자
    -비밀번호는 화면에서 가려질 뿐, 전송 자체가 암호화되는 것은 아님

2장 입력 양식
    -<input type="text"> : 한 줄 입력 / password : 비밀번호 입력
    -hidden : 화면에 보이지 않는 값 / tel : 전화번호 입력
    -number : 숫자 입력 / min·max : 최솟값·최댓값
    -email : 이메일 형식 검사 / date : 날짜 선택 / file : 파일 선택
    -radio : 같은 name끼리 하나만 선택 / checkbox : 여러 항목 선택
    -checked : 기본 선택 상태
    -submit : 폼 제출 / reset : 초기값으로 복원 / button : 일반 버튼
    -<select><option> : 선택 목록 / multiple : 여러 항목 선택
    -<textarea> : 여러 줄 입력 / cols·rows : 표시할 열·행 크기
    -size : 입력창 표시 크기 또는 목록의 표시 항목 수
    -파일 전송 시 form에 method="post", enctype="multipart/form-data" 지정

3장 입력 도움말과 그룹
    -<label for="입력요소id"> : 설명과 입력 요소 연결
    -<fieldset> : 관련 입력 항목 묶기 / <legend> : 그룹 제목
    -placeholder : 입력 전 도움말 / autofocus : 초기 포커스
    -autocomplete="off" : 자동완성을 끄도록 브라우저에 요청
    -id : 요소 식별자 / name : 폼 데이터 전송용 이름

4장 HTML 유효성 검사
    -required : 필수 입력 / minlength="2" : 최소 2글자
    -pattern : 입력값이 정규표현식에 맞는지 검사
    -title : 입력 형식 안내 문구
    -placeholder의 안내만으로 입력 조건이 검사되지는 않음
    -required가 없으면 빈 값은 일반적으로 pattern 검사 대상이 아님

5장 JavaScript 유효성 검사
    -onsubmit="return chk()" : 제출할 때 검사 함수 실행
    -입력요소.value : 입력값 / trim() : 앞뒤 공백 제거
    -length : 문자열 길이 / !값 : 값이 비어 있는지 등의 조건 판단
    -alert() : 안내창 / focus() : 해당 입력창으로 커서 이동
    -return false; : 제출 중단 / 검사 통과 시 return true;
    -게시판 예제 : 제목 필수, 작성자 이름 2글자 이상 검사
    -비밀번호 예제의 의도 : 아이디·비밀번호 4글자 이상, 확인값 일치 검사

6장 정규표현식
    -\d : 숫자 / \D : 숫자가 아닌 문자
    -\w : 영문자·숫자·밑줄(_) / \W : 그 외 문자 (기본 의미)
    -\s : 공백·탭·줄바꿈 등의 공백 문자
    -. : 보통 줄바꿈을 제외한 한 문자 / \. : 마침표 자체
    -{n} : 정확히 n회 / {n,} : n회 이상 / {2,4} : 2~4회
    -? : 0~1회 / + : 1회 이상 / * : 0회 이상
    -[a-z] : 소문자 범위 / ( ) : 그룹 / | : 또는
    -전화번호 예제 : \d{2,3}-?\d{3,4}-?\d{4}
    -의미 : 숫자 2~3자리 + 선택적 하이픈 + 3~4자리 + 선택적 하이픈 + 4자리
    -예제 이메일 패턴은 연습용이며 모든 유효한 이메일을 처리하지는 않음

7장 블록형과 인라인형 태그
    -블록형 : 기본적으로 새 줄에서 시작하며 가로 공간을 차지함
    -대표 예 : <div>, <p>, <ul> / <li>도 기본적으로 세로 목록 배치
    -인라인형 : 문장 흐름 안에서 필요한 너비만 차지함 / 대표 예 : <span>
    -06_블록형태그_라인형태그.html과 6_블록형태그_라인형태그.html은 같은 내용

8장 공간 분할과 시맨틱 태그
    -<div> : 영역을 나누는 일반적인 컨테이너
    -div에 header·nav·content·footer 등의 id를 붙여 영역 구분
    -<header> : 머리말 / <nav> : 탐색 메뉴
    -<section> : 주제별 내용 영역 / <footer> : 하단 정보
    -시맨틱 태그 : 영역의 역할과 의미를 태그 이름으로 표현
    -#footer p : id가 footer인 요소 내부의 p 선택
    -footer p : footer 태그 내부의 p 선택

9장 CSS와 종합 실습
    -width : 너비 / margin: 10px auto; : 위아래 여백과 좌우 중앙 배치
    -border: 1px solid red; : 빨간 실선 테두리
    -border-collapse: collapse; : 표의 인접 테두리 합치기
    -padding: 5px 10px; : 안쪽 여백, 위아래 5px·좌우 10px
    -font-weight: bold; : 굵게 / color : 글자색 / font-size : 글자 크기
    -9_quiz.html : 필수·추가 입력을 나눈 회원가입 폼 연습
