CSS 단위 · 박스 모델 · 글자 · 위치 배치 요점 정리
대상: 첨부 HTML 예제 12개
※ 소스 기준 요약. 연결된 이미지·폰트 파일과 외부 서비스의 동작은 확인하지 않았다.

1장 크기 단위 (1_단위들)
    -px: CSS 픽셀 단위. 예: font-size: 24px;
    -em: font-size에 사용하면 부모 글꼴 크기를 기준으로 배율을 지정한다.
      부모가 16px이면 0.8em은 12.8px, 0.5em은 8px이다.
    -%: 속성에 따라 기준이 달라진다. font-size: 100%는 부모 글꼴 크기와 같다.
      100%가 항상 16px인 것은 아니다.
    -pt: 포인트 단위. CSS 기준 3pt = 4px이므로 24pt = 32px이다.
    -text-align: justify; → 문단을 양쪽 정렬한다.
    -span에 display: block;을 지정해 날짜를 별도 줄로 표시한다.
    -실제 코드 주의: p와 span이 번갈아 있어 p는 1·3·5·7번째 자식이다.
      p:nth-child(1)은 첫 p, p:nth-child(3)은 두 번째 p를 선택한다.
      p:nth-child(2), p:nth-child(4)는 대상이 없어 100%와 24pt가 적용되지 않는다.
    -p:nth-child(2n+1)은 이 구조의 모든 p에 분홍 배경을 적용한다.
    -문단만 따로 세려면 p:nth-of-type(1)~p:nth-of-type(4)를 사용한다.

2장 url()과 배경·폰트 (2_url함수)
    -url('경로'): 이미지나 폰트 같은 외부 자원의 위치를 지정한다.
    -@font-face: 폰트 파일에 사용할 이름을 붙이고 font-family로 적용한다.
    -소스의 scr: url(...)은 오타이며 src: url(...)로 고쳐야 폰트가 연결된다.
    -font-family에 여러 글꼴을 나열하면 앞 글꼴을 사용할 수 없을 때 뒤 글꼴을 사용한다.
    -배경 설정 center no-repeat: 배경 이미지를 가운데 배치하고 반복하지 않는다.
    -background-size: 100%; → 배경 이미지 너비를 배경 배치 영역의 100%로 맞춘다.
      높이는 자동 계산하므로 이미지가 영역 전체를 반드시 채우는 것은 아니다.
    -부모 너비 600px, 자식 width: 80%이므로 자식 내용 너비는 480px이다.
    -부모 높이 400px, 자식 height: 100%이므로 자식 내용 높이는 400px이다.
      기본 content-box에서는 자식 테두리 2px가 별도로 더해진다.
    -text-align과 line-height를 이용해 한 줄 글자를 가로·세로 가운데 배치한다.

3장 display 속성 (3_display)
    -block: 새 줄에서 시작하는 블록 배치. width와 height를 적용할 수 있다.
    -inline: 글자 흐름 안에 배치. 일반적인 비대체 인라인 요소에는 width·height가
      적용되지 않으며, 위·아래 margin도 블록처럼 줄 간격을 벌리지 않는다.
    -inline-block: 한 줄에 나란히 배치하면서 width·height를 적용할 수 있다.
    -none: 요소를 표시하지 않고 레이아웃 공간도 제거한다.
    -예제의 3번째 div는 inline, 4번째는 숨김, 5·6번째는 inline-block이다.
    -1·2·7번째 div는 블록 배치다. inline-block 사이는 HTML 공백 때문에 틈이 생길 수 있다.

4장 visibility와 opacity (4_visibility)
    -visibility: hidden; → 보이지 않지만 원래 차지하던 공간은 유지한다.
    -display: none; → 보이지 않고 공간도 제거한다.
    -opacity: 0~1로 요소 전체의 불투명도를 지정한다.
      0은 완전 투명, 1은 완전 불투명이며, 자식과 글자에도 함께 영향을 준다.
    -opacity: 0은 공간을 유지하며 투명해도 클릭 대상이 될 수 있다.
    -실제 코드의 id=" visibility", id=" display"에는 앞 공백이 있다.
      id="visibility", id="display"로 수정해야 작성한 CSS 선택자와 일치한다.
    -현재 소스에는 opacity 설정이 없으며, '반투명' 등의 글자만 작성되어 있다.
    -주석의 opercity는 opacity의 오타다.

5장 margin·padding·border (5_margin_paddinbg_border)
    -content: 실제 내용 영역. padding: 내용과 테두리 사이 안쪽 여백.
    -border: 테두리. margin: 테두리 바깥 여백.
    -기본 content-box에서 바깥 테두리까지의 폭:
      width + 좌우 padding + 좌우 border.
    -예제 div의 내용 크기는 모두 100×100px이다.
      div0: 추가 여백·테두리 없음 → 테두리 영역 기준 100×100px.
      div1: padding 10px → 120×120px.
      div2: margin 10px → 박스 자체는 100×100px, 바깥에 여백 추가.
      div3: border 10px → 120×120px.
      div4: padding 10px + border 10px → 140×140px, 바깥 margin 10px 추가.
    -margin은 배경색이 칠해지는 영역에 포함되지 않는다.
    -세로 방향의 블록 margin은 조건에 따라 서로 겹칠 수 있어 단순 합산과 다를 수 있다.
    -값 1개는 네 방향, 2개는 위·아래 / 좌·우, 4개는 위 → 오른쪽 → 아래 → 왼쪽.
    -solid는 실선, dashed는 점선 형태의 테두리다.

6장 box-sizing (6_box-sizing)
    -content-box: width·height가 내용 영역 크기이며 padding과 border가 추가된다.
    -border-box: width·height 안에 padding과 border를 포함한다. margin은 제외한다.
    -첫 번째 div: 100×100px.
    -두 번째 div: border-box와 5px 테두리 → 전체 100×100px, 내용은 90×90px.
    -세 번째 div: content-box와 5px 테두리 → 전체 110×110px.
    -메뉴 li에 border-box를 지정해 테두리를 지정 폭 안에 포함한다.
    -부모 ul 폭은 450px, li 폭은 30.3%씩이다. 세 항목 합계는 90.9%여서 빈 공간이 남는다.
      정확히 3등분하려는 의도라면 width: calc(100% / 3); 등으로 조정한다.
    -a에 display: block;과 padding을 적용해 링크 영역을 넓힌다.

7장 line-height와 원형 버튼 (7_lineheight)
    -line-height: 텍스트의 줄 상자 높이를 지정한다.
    -예제는 width·height를 모두 300px, border-radius를 150px로 지정해 원형을 만든다.
    -text-align: center; → 글자 가로 가운데 배치.
    -line-height: 300px; → 높이 300px 영역 안에서 한 줄 글자를 세로 가운데 배치한다.
    -여러 줄 텍스트에는 이 방식이 적합하지 않다.
    -화면에 BUTTON이라고 표시하지만 실제 요소는 div이므로 버튼 동작은 없다.

8장 글꼴과 글자 스타일 (8_글자관련)
    -localfont: 프로젝트의 ttf 파일을 @font-face로 등록하여 적용한다.
    -webfont: Google Fonts 스타일시트를 연결하여 East Sea Dokdo 글꼴을 사용한다.
    -font-family: 글꼴 목록. font-style: italic / normal로 기울임 여부 지정.
    -font-weight: 글자 굵기. text-decoration: underline;은 밑줄.
    -line-height: 40px;로 줄 높이를 설정한다.
    -오타: font-weight: 400px; → font-weight: 400;
      굵기의 숫자 값에는 px 같은 길이 단위를 붙이지 않는다.
    -webfont 문단의 '로컬 존재'라는 글과 달리 실제 글꼴 연결은 외부 웹폰트다.
    -한글 인코딩을 명확히 하려면 head에 <meta charset="utf-8">을 추가한다.

9장 position: absolute (9_position_absoute)
    -기본 position 값은 static이다. 주석의 statick은 오타다.
    -absolute: 일반 문서 흐름에서 빠져 배치되며 원래 자리를 확보하지 않는다.
    -이 예제에서는 가장 가까운 position이 static이 아닌 조상을 기준으로 배치한다.
      해당 조상이 없는 바깥 div들은 초기 컨테이닝 블록을 기준으로 배치된다.
    -top·left: 기준 영역의 위쪽·왼쪽에서 떨어진 거리.
    -div1: top 0, left 0. div2: top 100px, left 100px.
    -div3: top 350px, left 350px, 크기 300×300px.
    -div4는 div3 안에 있고 div3도 absolute이므로 div3을 기준으로 50px씩 떨어진다.
    -opacity: 0.7로 겹친 영역이 비쳐 보이며 div3만 opacity: 1이다.

10장 position: fixed와 z-index (9_position_fixed)
    -fixed: 이 예제에서는 브라우저 뷰포트를 기준으로 위치를 고정한다.
    -div2는 top 100px, left 100px에 고정되어 문서를 스크롤해도 같은 화면 위치를 유지한다.
    -fixed 역시 일반 흐름에서 빠져 별도 공간을 확보하지 않는다.
    -z-index: 겹치는 요소의 쌓임 순서를 조절한다.
    -예제에서는 div2의 z-index가 100, div3이 50이므로 겹치면 div2가 위에 표시된다.
    -z-index는 쌓임 맥락 안에서 비교된다. 모든 요소를 숫자 하나로 비교하는 것은 아니다.

11장 position: relative와 자식 기준점 (9_position_relative)
    -relative: 원래 배치 위치를 기준으로 이동하며 원래 자리의 공간은 유지한다.
    -container는 너비 100px로 가운데 배치한 뒤 left: 10px로 오른쪽으로 이동한다.
    -relative 부모는 absolute 자식의 위치 기준이 된다.
    -green은 container의 top 0, left 0에 놓이며 100×100px, opacity 0.5이다.
    -green은 absolute이므로 부모의 일반 흐름 높이를 늘리지 않는다.
    -TEXT 요소는 일반 흐름에 남아 있고 green과 같은 영역에 겹칠 수 있다.

12장 float로 이미지와 본문 배치 (10_float)
    -float: left; → 이미지를 왼쪽에 놓고 글이 오른쪽과 아래쪽으로 흐른다.
    -float: right; → 이미지를 오른쪽에 놓고 글이 왼쪽과 아래쪽으로 흐른다.
    -첫 이미지 margin: 20px 15px 0 0; → 위 20px, 오른쪽 15px 여백.
    -두 번째 이미지 margin: 20px 0 0 15px; → 위 20px, 왼쪽 15px 여백.
    -본문에는 text-align: justify;를 사용한다.
    -글이 짧으면 float 이미지가 부모 밖으로 나갈 수 있다.
      부모에 display: flow-root;를 주면 float를 포함하는 영역을 만들 수 있다.
    -이미지 뒤 요소가 옆으로 흐르지 않게 하려면 clear 속성을 사용할 수 있다.

핵심 정리
    -크기: px·em·%·pt / 표시 방식: display / 숨김: visibility / 투명도: opacity.
    -박스: content → padding → border → margin.
    -border-box는 지정 크기에 padding·border를 포함하고 margin은 포함하지 않는다.
    -relative는 원래 자리 기준, absolute는 기준 조상에 따른 배치,
      fixed는 이 예제에서 화면 기준 고정, float는 글의 흐름을 감싸도록 배치한다.
