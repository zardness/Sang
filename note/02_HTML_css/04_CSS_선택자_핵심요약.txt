1장 선택자 기본
    -선택자 : CSS를 적용할 HTML 요소를 지정
    -기본 문법 : 선택자 { 속성: 값; }
    -태그 선택자 : p, h1, div 등 해당 태그 선택
    -그룹 선택자 : header, footer처럼 쉼표로 여러 대상 선택
    -같은 우선순위의 규칙이 충돌하면 나중에 작성한 속성값 적용

2장 전체·id·class·혼합 선택자
    -* : 모든 요소 선택 / margin:0; padding:0; 등 초기화에 사용
    -#header : id가 header인 요소 / id는 문서 안에서 고유하게 지정
    -.odd : class가 odd인 요소 / 여러 요소에 같은 class 사용 가능
    -class="menu1 odd" : 하나의 요소에 여러 클래스 지정
    -div#wrap : div이면서 id가 wrap인 요소
    -li.odd : li이면서 class가 odd인 요소

3장 속성 선택자
    -input[type='password'] : 속성값이 정확히 password인 input
    -input[type^='te'] : type 값이 te로 시작하는 input
    -input[name$='me'] : name 값이 me로 끝나는 input
    -img[alt] : alt 속성이 있는 img
    -a[href$='.docx'] : 링크 주소가 .docx로 끝나는 a
    -실습 : 입력창 종류별 디자인, 문서 확장자별 배경 아이콘 표시

4장 자식·후손 선택자
    -div p : div 내부의 모든 후손 p 선택
    -div > p : div 바로 아래의 자식 p만 선택
    -#wrap #content .odd : wrap 내부 content 내부의 odd 클래스 선택
    -공백은 여러 단계 아래까지, >는 바로 한 단계 아래만 선택

5장 형제(동위) 선택자
    -h3 + div : 같은 부모 아래에서 h3 바로 다음 요소가 div일 때 선택
    -h3 ~ div : 같은 부모 아래에서 h3 뒤에 나오는 모든 div 선택
    -앞쪽 형제나 자식 요소는 선택하지 않음

6장 반응·상태 선택자
    -:hover : 마우스 포인터가 올라간 상태 / 예 : tr:hover
    -:focus : 입력창 등에 포커스가 있는 상태
    -:enabled : 활성화된 폼 요소 / :disabled : 비활성화된 폼 요소
    -:read-only : 사용자가 편집할 수 없는 요소 선택
    -disabled : 일반적으로 포커스 불가, 폼 제출값에서 제외
    -readonly : 텍스트 입력 수정 불가, 포커스와 값 전송은 가능

7장 구조 선택자
    -:first-child : 부모의 첫 번째 자식 / :last-child : 마지막 자식
    -:nth-child(2n) : 짝수 번째 / :nth-child(2n+1) : 홀수 번째
    -li:nth-child(3) : 전체 형제 요소 중 세 번째이면서 li인 요소
    -자식 순서는 1부터 계산하며, 같은 태그만 세는 것은 아님
    -실습 : 홀짝 메뉴 색상 변경, 첫 메뉴와 마지막 메뉴 모서리 처리
    -10_구조선택자.html은 기본 HTML 구조만 있고 본문은 비어 있음

8장 문자·가상 요소·부정 선택자
    -::first-line : 화면에 표시되는 첫 줄 / 줄바꿈 위치에 따라 대상이 달라짐
    -::first-letter : 첫 글자
    -::after : 요소 내용 뒤에 생성 콘텐츠 추가 / 예제의 :after와 같은 용도
    -content: '-' attr(href); : 하이픈과 해당 요소의 href 값을 표시
    -li:not(.web) a : web 클래스가 없는 li 내부의 a 선택

9장 메뉴와 레이아웃 CSS
    -float:left; : 요소를 왼쪽으로 띄워 가로 배치
    -overflow:hidden; : 넘친 부분 숨김, 예제에서는 float 자식을 감싸는 데도 사용
    -clear:both; : 앞선 좌우 float 옆에 놓이지 않도록 아래로 배치
    -list-style:none; : 목록 기호 제거 / text-decoration:none; : 링크 밑줄 제거
    -margin:0 auto; : 너비가 지정된 블록을 좌우 중앙 배치
    -font-size:1.5em; : 부모 글자 크기의 1.5배
    -border-radius : 모서리 둥글게 / 4개 값 순서 : 좌상·우상·우하·좌하
    -기본 박스 크기 : 내용 너비 + 좌우 padding + 좌우 border
    -가로 메뉴는 li에 float:left 적용 / 세로 메뉴는 기본 세로 배치 사용
    -12_quiz.html : header·content·footer를 각각 left·center·right로 분할
