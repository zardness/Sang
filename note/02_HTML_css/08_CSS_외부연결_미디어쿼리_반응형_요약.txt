1장 외부 CSS 연결 (ex1_link.html)
    -<link href="파일.css" rel="stylesheet"> : 외부 CSS 적용
    -title.css·footer.css : 제목과 하단 영역의 스타일 파일 연결
    -media="screen" : 화면에서 적용 / media="print" : 인쇄할 때 적용
    -content-pc.css와 content-print.css를 구분하여 화면·인쇄 스타일 연결
    -HTML 구조 : #wrap 안에 .title·.content·.footer 배치
    -주석 처리된 <style> 코드는 적용되지 않음

2장 @import와 @media (ex2_규칙.html)
    -@import url('파일.css'); : CSS 안에서 다른 CSS 불러오기
    -@import는 일반 스타일 규칙보다 앞에 작성
    -@media screen { ... } : 화면용 스타일
    -@media print { ... } : 인쇄용 스타일
    -예제의 내부 screen·print 규칙은 본문 색상·여백·정렬 값이 같음
    -뒤에 연결된 외부 CSS와 같은 속성이 겹치면 우선순위에 따라 적용
    -다른 우선순위 조건이 같을 때는 나중에 작성된 규칙이 적용됨

3장 반응형 웹 기본 (ex3_반응형.html)
    -반응형 웹 : 화면 너비에 따라 크기·배치·표시 항목 변경
    -meta viewport의 width=device-width : 기기 화면 너비에 맞춰 표시
    -initial-scale=1.0 : 초기 확대 배율 1
    -공통 스타일을 먼저 작성하고 @media에서 화면별 스타일 지정
    -min-width : 해당 너비 이상 / max-width : 해당 너비 이하
    -and : 여러 조건을 모두 만족할 때 적용
    -스마트폰·태블릿·PC라는 이름은 예제의 구분이며 실제 조건은 화면 너비

4장 화면 너비별 변화
    -849px 이하 : 분홍 배경, 너비 99%, 바깥 여백 0.5%, 글자 1.2em
    -849px 이하 : menu2·menu4 숨김, 나머지 3개 메뉴 너비 각각 33.3%
    -850~1200px : 연두 배경, 글자 1.1em
    -850~1200px : menu4 숨김, 나머지 4개 메뉴 너비 각각 25%
    -1201px 이상 : 전체 너비 800px, 좌우 중앙 배치
    -1201px 이상 : 5개 메뉴 모두 표시, 너비 각각 20%

5장 주요 CSS 문법
    -* {margin:0; padding:0;} : 기본 여백 초기화
    -float:left; : 메뉴 가로 배치 / list-style:none; : 목록 기호 제거
    -box-sizing:border-box; : 지정 너비에 padding·border 포함
    -display:none; : 요소와 배치 공간 숨김
    -li:nth-child(2) : 두 번째 자식이면서 li인 요소 선택
    -margin:0 auto; : 너비가 지정된 블록을 좌우 중앙 배치
    -line-height : 줄 높이 / 한 줄 메뉴 글자를 세로 중앙에 배치할 때 활용
    -text-align:justify; : 양쪽 정렬 / center : 가운데 정렬

6장 확인 사항
    -ex1·ex2가 연결하는 css 폴더의 외부 파일은 이번 첨부에 없어 내용 확인 불가
    -ex1·ex2의 footer에 여는 <p> 없이 작성된 </p> 정리 필요
    -Written ny → Written by로 수정
    -ex3에는 JavaScript 동작 없이 CSS 미디어 쿼리만으로 화면 변화 구현
    -브라우저 너비를 바꾸며 3개·4개·5개 메뉴 표시를 확인하는 실습
