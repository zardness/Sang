CSS 선택자 종류와 활용 요점 정리
대상: 첨부 HTML 예제 14개
※ 10_구조선택자(1).html은 기본 HTML 틀만 있고 실제 예제는 비어 있다.

1장 선택자와 태그 선택자 (01)
    -선택자: 스타일을 적용할 HTML 요소를 지정하는 규칙.
    -기본 형식: 선택자 { 속성: 값; }
    -h1, p, li처럼 태그 이름으로 해당 요소를 선택한다.
    -header, footer처럼 쉼표로 나열하면 여러 선택 대상에 같은 스타일을 적용한다.
    -예제는 header·footer에 회색 실선, h1에 빨간 점선과 밑줄을 적용한다.
    -li와 p에 빨간 글자·연한 배경색을 지정한 뒤, p에 파란 글자·굵기를 추가한다.
    -p는 최종적으로 파란색·굵은 글자가 되며 앞에서 지정한 배경색은 유지된다.
    -CSS는 무조건 아래쪽 규칙이 이기는 것은 아니다. 동일한 출처·중요도·레이어
      조건에서는 선택자 명시도가 우선이며, 명시도까지 같으면 뒤의 선언이 우선한다.
    -이 예제 범위의 기본 명시도: id > class·속성·가상 클래스 > 태그.

2장 전체 선택자와 기본 배치 (02)
    -*: 모든 요소 선택. 예제는 margin과 padding을 0으로 초기화한다.
    -header, nav, section, footer의 너비를 500px로 지정한다.
    -margin: 5px auto; → 위·아래 5px, 좌·우 자동 여백으로 가운데 배치.
    -nav ul li: nav 내부 ul의 후손 li 선택.
    -float: left;와 width: 25%;로 메뉴 4개를 가로로 배치한다.
    -list-style: none; → 목록 기호 제거. text-align: center; → 내용 가운데 정렬.
    -부모의 overflow: hidden;은 이 예제에서 float 자식의 높이를 포함하도록 한다.
      동시에 영역을 넘는 내용을 잘라낼 수도 있다.
    -clear: both;는 앞선 float 옆에 요소가 배치되지 않도록 한다.
      기존 요소의 float 속성 자체를 삭제하는 것은 아니다.
    -오타: border: 1px solid,gray; → border: 1px solid gray;

3장 id와 class 선택자 (03)
    -#header: id="header"인 요소 선택. id는 문서 안에서 고유하게 지정한다.
    -.odd: class에 odd가 포함된 요소 선택. class는 여러 요소에 재사용할 수 있다.
    -class="menu1 odd": 하나의 요소에 두 클래스를 부여한다.
    -#wrap #content .odd: wrap 내부 content 안에서 odd 클래스를 가진 요소 선택.
    -메뉴 1·3·5는 odd 클래스로 글자 크기를 키우고, 메뉴 2·4는 menu2로 굵게 표시한다.
    -font-size: 1.5em; → 해당 요소의 글꼴 크기를 부모 글꼴 크기의 1.5배로 지정한다.
    -본문과 배너를 float: left;로 나란히 배치한다.
    -기본 content-box 기준 본문 폭: 348px + 좌우 테두리 2px = 350px.
    -배너 폭: 248px + 좌우 테두리 2px = 250px. 합계 600px로 부모 내용 폭에 맞춘다.

4장 혼합 선택자 (04)
    -div#wrap: div이면서 id가 wrap인 요소.
    -li.odd: li이면서 odd 클래스를 가진 요소.
    -div#header, div#footer: header인 div 또는 footer인 div를 함께 선택한다.
      한 요소가 두 id를 모두 가진다는 뜻이 아니다.
    -공백 없이 붙이면 같은 요소의 조건을 결합하고, 공백을 넣으면 후손 관계가 된다.
    -예: div#wrap div#content li.odd → wrap 내부 content 안의 odd 클래스 li.
    -03·04 예제의 배너 주소는 daun.net으로 적혀 있다. 다음 링크 의도라면
      daum.net으로 철자를 확인하여 수정한다.

5장 속성 선택자 (05_속성선택자)
    -[속성]: 해당 속성이 존재하는 요소.
    -[속성='값']: 속성값이 정확히 일치하는 요소.
    -[속성^='값']: 해당 문자열로 시작하는 요소.
    -[속성$='값']: 해당 문자열로 끝나는 요소.
    -input[type='password']: 비밀번호 입력칸의 글자색을 검정으로 지정한다.
    -input[type^='te']: text와 tel 입력칸에 너비 100px와 주황 글자색을 적용한다.
    -input[name$='me']: name="name"인 입력칸에 빨간 테두리와 안쪽 여백을 적용한다.
    -img[alt]: alt 속성이 있는 이미지에만 너비 50px와 빨간 테두리를 적용한다.
    -소스의 완성된 첫 img에는 alt가 없어 img[alt] 규칙이 적용되지 않는다.
    -마지막 <img src 부분은 미완성 태그이므로 속성과 태그를 완성해야 한다.
    -outline은 border와 별개인 외곽선이다. outline을 없애면 초점 위치를 알 수 있도록
      다른 시각적 표시를 제공하는 것이 좋다.

6장 속성값에 따라 아이콘 표시 (05_속성선택자2)
    -h4[title^='남자'], h4[title^='여자']: title의 시작 문자열에 따라 배경 아이콘 설정.
    -background: url(...) no-repeat; → 배경 이미지를 반복하지 않는다.
    -왼쪽 padding 30px로 아이콘과 제목 글자 사이 공간을 확보한다.
    -a[href$='.docx'], a[href$='.doc']: 워드 파일 링크에 워드 아이콘 표시.
    -a[href$='.xlsx'], a[href$='.xls']: 엑셀 파일 링크에 엑셀 아이콘 표시.
    -no-repeat right와 오른쪽 padding으로 링크 오른쪽에 아이콘 공간을 만든다.
    -이 규칙은 href 문자열의 끝을 검사한다. 확장자 뒤에 쿼리가 붙으면 일치하지
      않을 수 있으며, 실제 파일 내용이나 형식을 검사하는 기능은 아니다.
    -아이콘과 연결 문서가 해당 경로에 실제로 있어야 표시·열기가 가능하다.

7장 자식과 후손 선택자 (06)
    -div p: div 내부의 모든 깊이에 있는 후손 p를 선택한다.
    -div > p: div의 바로 아래 자식 p만 선택한다.
    -예제의 바로 아래 p는 빨간색, ul → li 안쪽의 p는 파란색이다.
    -직접 자식 p에는 두 규칙이 모두 해당한다. 두 선택자의 명시도가 같으므로
      뒤에 작성한 div > p의 빨간색이 적용된다.
    -'>'가 있다는 이유만으로 후손 선택자보다 명시도가 높아지는 것은 아니다.

8장 형제 선택자 (07)
    -A + B: 같은 부모 안에서 A 바로 다음에 있는 B 요소 하나를 선택한다.
    -A ~ B: 같은 부모 안에서 A 뒤에 나오는 B 요소들을 선택한다.
    -h3 ~ div: h3 뒤의 div_01~div_05를 주황색으로 표시한다.
    -h3 + div: 바로 다음 div_01만 글자 크기를 1.5em으로 지정한다.
    -h3 앞의 div_00에는 두 규칙이 적용되지 않는다.
    -미완성 선언 font-w는 제거하거나 올바른 CSS 속성·값으로 완성한다.

9장 반응 선택자 (08)
    -:hover: 포인터가 요소 위에 올라간 상태를 선택하는 가상 클래스.
    -tr:hover: 마우스를 올린 표 행의 배경을 초록, 글자를 노랑으로 바꾼다.
    -기본 행 배경은 lightgreen이며, 포인터가 벗어나면 기본 스타일로 돌아간다.
    -tr 전체를 대상으로 하므로 본문 행뿐 아니라 제목 행에도 적용된다.
    -border-collapse: collapse;로 표 경계를 합치고 th·td에 빨간 테두리를 적용한다.

10장 상태 선택자 (09)
    -:focus: 현재 입력 초점을 가진 요소.
    -:enabled: 활성화된 입력 요소. :disabled: 비활성화된 입력 요소.
    -:read-only: 사용자가 편집할 수 없는 요소. readonly 속성만 찾는 선택자는 아니다.
    -disabled 입력칸: 수정 불가, 일반적으로 초점 이동 불가, 폼 제출 데이터에서 제외.
    -readonly 텍스트 입력칸: 수정 불가, 초점 이동·선택 가능, name이 있으면 제출됨.
    -예제에서는 시급 sal이 disabled, 생일 birth가 readonly다.
    -input:read-only는 읽기 전용·비활성 텍스트 입력칸뿐 아니라
      텍스트 편집 대상이 아닌 submit 입력에도 해당할 수 있다.
    -오타: color: balck; → color: black;
    -누락: border: 2px solid green 뒤에 세미콜론을 추가한다.
      현재는 outline:none과 한 선언으로 이어져 테두리 선언이 무효가 된다.

11장 구조 선택자와 가로·세로 메뉴 (10)
    -:nth-child(2n): 형제 요소 중 짝수 번째. :nth-child(2n+1): 홀수 번째.
    -:first-child / :last-child: 부모의 첫 번째 / 마지막 자식.
    -순서는 1부터 센다. li:nth-child는 li만 따로 세는 것이 아니라
      모든 형제 요소의 순서를 센 후 그 요소가 li인지 확인한다.
    -예제는 짝수 메뉴를 노랑, 홀수 메뉴를 주황으로 표시한다.
    -첫 메뉴와 마지막 메뉴는 뒤의 규칙이 적용되어 lightgrey가 된다.
    -가로 메뉴: 부모 폭 800px, li에 float: left; 적용.
    -세로 메뉴: 부모 폭 400px, li에 float를 주지 않아 위아래로 배치.
    -border-radius 값 4개의 순서: 왼쪽 위 → 오른쪽 위 → 오른쪽 아래 → 왼쪽 아래.
    -가로 메뉴는 처음·끝의 좌우 바깥 모서리, 세로 메뉴는 위·아래 모서리를 둥글게 한다.
    -text-decoration: none;으로 링크 밑줄을 없앤다.
    -세로 메뉴 파일 하단의 중복 </head>, <body>를 정리해야 한다.
    -10_구조선택자(1).html은 빈 기본 문서이며 가로·세로 메뉴 파일에 실제 예제가 있다.

12장 문자·생성 콘텐츠·부정 선택자 (11)
    -::first-line: 화면에 표시되는 첫 줄. 화면 폭이나 글꼴에 따라 적용 범위가 달라진다.
    -::first-letter: 첫 글자 부분. 예제는 두 번째 문단 첫 글자를 크게 표시한다.
    -두 번째·세 번째 문단의 첫 줄은 파랑·굵게·20px로 표시한다.
    -p:nth-child(3) span 규칙은 있지만 해당 문단에 span이 없어 적용 대상이 없다.
    -::after: 요소 내용 뒤에 생성 콘텐츠를 추가하는 가상 요소.
    -예제의 a:after는 이전 단일 콜론 표기이며 ::after로도 쓸 수 있다.
    -content: '-' attr(href); → 링크 글자 뒤에 '-'와 href 속성 문자열을 표시한다.
    -:not(.web): web 클래스가 없는 요소 선택.
    -li:not(.web) a: web 클래스가 없는 li 내부의 링크 배경을 노랗게 한다.
      예제에서는 '다음'을 제외한 네이버·구글·줌 링크가 해당한다.
    -text-align: justify; → 문단 양쪽 정렬.
    -target="_blank": 링크를 새 탐색 창이나 탭에서 연다.
    -줌 링크의 http:/zum.com은 슬래시가 하나 빠져 있어 올바른 주소로 수정한다.
    -footer의 float와 padding은 현재 ul에 적용되어 있다.
      이미지 항목을 가로 배치하려는 의도라면 해당 선택자를 #footer ul li로 조정한다.

핵심 암기
    -태그: p / 전체: * / id: #name / class: .name / 속성: [type='text']
    -후손: A B / 직접 자식: A > B / 바로 다음 형제: A + B / 뒤쪽 형제: A ~ B
    -반응·상태: :hover, :focus, :enabled, :disabled, :read-only
    -구조: :nth-child(), :first-child, :last-child
    -문자·생성 콘텐츠: ::first-line, ::first-letter, ::after / 제외 조건: :not()
    -선택 대상과 명시도, 작성 순서를 구분해서 최종 스타일을 판단한다.
