1장 HTML, CSS, JavaScript 기초
    -HTML : 웹문서의 구조와 내용 작성
    -CSS : 배경색, 글자 크기 등 디자인 설정
    -JavaScript : 사용자 입력, 조건 처리 등 동작 구현

2장 HTML 기본 구조
    -<!DOCTYPE html> : HTML5 문서 선언
    -<html> : HTML 문서의 시작과 끝 / lang="en"은 영어 지정
    -<head> : 문자 인코딩, 제목, CSS·JavaScript 연결 등 설정 정보
    -<meta charset="utf-8"> : UTF-8 문자 인코딩 지정
    -<title> : 브라우저 탭에 표시할 제목
    -<body> : 화면에 표시할 내용
    -<br> / <br /> : 줄바꿈
    -&nbsp; : 줄바꿈되지 않는 공백
    -<!-- 내용 --> : HTML 주석

3장 CSS 기본 문법
    -body { 속성: 값; } : body 요소에 디자인 적용
    -background-color: yellow; : 배경색을 노란색으로 지정
    -font-size: 30pt; : 글자 크기를 30포인트로 지정
    -/* 내용 */ : CSS 주석

4장 JavaScript 기본 문법
    -prompt("이름은?", "홍길동") : 입력창 표시 / 기본 입력값은 홍길동
    -prompt() 반환값 : 확인하면 문자열 / 취소하면 null
    -if (조건) { 실행문 } : 조건이 참일 때 실행
    -!= : 같지 않음 / !== : 자료형까지 구분하여 같지 않음 비교
    -&& : 두 조건이 모두 참일 때 참
    -'' : 빈 문자열 / + : 문자열 연결
    -document.write() : 문서에 문자열이나 HTML 출력
    -// 내용 : 한 줄 주석 / /* 내용 */ : 여러 줄 주석

5장 내부 작성과 외부 파일 연결
    -1.html : <style>과 <script> 안에 CSS·JavaScript 직접 작성
    -2.html : HTML 구조와 내용 작성 / 2.css·2.js 연결
    -2.css : 디자인 코드 저장
    -2.js : 사용자 입력과 인사말 출력 코드 저장
    -<link href="2.css" rel="stylesheet"> : 외부 CSS 연결
    -<script src="2.js"></script> : 외부 JavaScript 연결
    -예제의 2.html, 2.css, 2.js는 같은 폴더에 배치

6장 실행 흐름과 주의사항
    -이름 입력창 표시 → 조건 확인 → 인사말 출력 → 본문 표시
    -원본의 'null'은 문자열이며, 취소 반환값 null과 다름
    -name은 브라우저의 window.name과 겹칠 수 있으므로 별도 변수 사용
    -권장 예시 : const userName = prompt("이름은?", "홍길동");
    -조건 예시 : if (userName !== null && userName !== '') { ... }
    -출력 예시 : document.write(userName + '님 방가방가<br><br>');
    -document.write()는 학습용 예제이며, 입력값을 HTML로 해석함
    -실제 화면의 텍스트 변경에는 요소의 textContent 사용 권장
