(첨부 6개 중 내용이 있는 노트북 5개 기준. Untitled.ipynb는 비어 있음)
※ 소스 내용을 요약했으며 데이터 다운로드·모델 학습은 실행하지 않음.

1장 머신러닝과 데이터 탐색
    -지도학습은 정답을 이용해 예측 규칙을 배우고, 비지도학습은 정답 없이 데이터 구조를 찾음
    -분류는 범주를 예측하고 회귀는 수치를 예측하며, 군집은 비슷한 데이터끼리 묶음
    -기본 흐름: 데이터 탐색 → 전처리 → 학습·평가 데이터 분리 → 모델 학습 → 평가·저장
    -X는 입력 특징(feature), y는 정답 또는 타겟(label)
    -describe(): 평균·표준편차·사분위수 등 요약 / value_counts(): 범주별 빈도 확인
    -mean·median은 중심 위치, var·std는 흩어진 정도를 확인
    -왜도는 분포의 비대칭, 첨도는 꼬리의 무거움 등을 나타내는 분포 형태 지표
    -dataprep.eda의 plot·plot_correlation·plot_missing으로 분포·상관·결측치 탐색
    -피어슨 상관계수는 선형 관계, 스피어만 상관계수는 순위 기반의 단조 관계를 측정
    -상관계수는 -1~1이며 상관관계만으로 원인과 결과를 판단할 수 없음
    -fisher_exact(): 소표본 2×2 교차표의 연관성 검정 예제
    -mcnemar(): 같은 대상의 전후 결과처럼 짝지어진 이진 결과의 변화 검정

2장 스케일 조정
    -변수의 단위·크기 차이를 조정하며 거리 기반 모델 등에 영향을 줌
    -fit(): 변환 기준 학습 / transform(): 기준 적용 / fit_transform(): 두 작업을 연속 수행
    -StandardScaler: (값 - 평균) / 표준편차
    -MinMaxScaler: (값 - 최솟값) / (최댓값 - 최솟값), 기본 학습 범위를 0~1로 조정
    -MaxAbsScaler: 각 열의 최대 절댓값으로 나눠 부호와 0을 보존
    -RobustScaler: 중앙값과 IQR을 사용해 극단값의 영향을 줄임
    -Normalizer: 각 행의 벡터 길이를 맞춤. 열별 표준화와 다른 처리
    -inverse_transform(): 지원하는 변환기에서 원래 척도로 되돌림
    -평가용 데이터에는 학습 데이터에서 구한 변환 기준만 적용

3장 인코딩과 결측값 처리
    -LabelEncoder: 범주를 0부터 시작하는 정수로 변환, classes_로 대응 범주 확인
    -inverse_transform(): 정수 레이블을 원래 범주로 복원
    -OneHotEncoder·LabelBinarizer: 범주별 표시 열로 변환
    -원핫 인코딩은 명목형 범주에 임의의 크기·순서 관계가 생기는 것을 피할 때 사용
    -평균값 인코딩: 범주별 타겟 평균을 해당 범주의 수치값으로 사용
    -타이타닉 예제는 성별 생존율을 계산해 성별을 수치로 표현
    -타겟을 이용하는 인코딩은 평가 데이터의 정답이 학습 과정에 섞이지 않도록 주의
    -isna().sum(): 결측치 개수 확인
    -SimpleImputer(strategy='mean'/'median'/'most_frequent'): 평균·중앙값·최빈값 대체
    -fillna()로도 대체 가능하며, 반환값을 저장해야 원본에 반영됨

4장 데이터 분리·모델 학습·저장
    -random.sample(), DataFrame.sample(), train_test_split()으로 데이터 분리
    -train_test_split(..., test_size=0.3): 테스트 데이터 비율을 30%로 지정
    -stratify=y는 클래스 비율을 유지하며 분리, random_state는 재현성을 위한 난수 설정
    -학습 데이터로 fit(), 평가 데이터로 predict()와 성능 측정
    -DecisionTreeClassifier는 규칙을 분기하고 MLPClassifier는 다층 신경망으로 분류
    -분류 모델의 score()는 일반적으로 정확도이며 모든 모델의 score 의미가 같은 것은 아님
    -pd.crosstab(실제값, 예측값) 또는 confusion_matrix()로 분류 결과 확인
    -pickle.dump()/load(), joblib.dump()/load()로 모델 저장·복원
    -모델과 함께 스케일러·인코더 등 예측에 필요한 전처리 기준도 보관

5장 K-Means 군집분석
    -정답을 사용하지 않고 중심점까지의 거리를 기준으로 K개 군집을 찾음
    -초기 중심 선택 → 가까운 중심으로 데이터 배정 → 군집 평균으로 중심 갱신 → 반복
    -n_clusters는 군집 수, init은 초기화 방법, n_init은 초기화 실행 횟수 설정
    -max_iter는 실행당 반복 상한, random_state는 초기화 재현성에 사용
    -fit_predict(X): 학습 후 군집 번호 반환
    -labels_: 학습 데이터의 군집 번호 / cluster_centers_: 군집 중심 좌표
    -predict(X): 학습한 중심을 기준으로 소속 군집 예측
    -군집 번호 0·1·2는 식별 번호로 실제 정답 클래스 번호와 일치할 필요가 없음
    -군집 크기·밀도가 다르거나 길고 휘어진 형태에서는 원하는 구조를 찾기 어려울 수 있음

6장 계층적 군집과 DBSCAN
    -계층적 군집은 가까운 데이터·군집을 차례로 합치며 계층 구조를 생성
    -linkage(..., method='complete'): 군집 간 가장 먼 점의 거리를 기준으로 결합
    -dendrogram(): 결합 과정을 나무 모양으로 시각화
    -fcluster(..., criterion='distance'): 거리 기준으로 나눔
    -criterion='maxclust': 지정한 최대 군집 수를 기준으로 나눔
    -DBSCAN은 밀도가 높은 영역을 연결하는 군집 방법
    -eps는 이웃 반경, min_samples는 핵심점 판정에 필요한 최소 이웃 수
    -군집 수를 직접 지정하지 않으며 labels_의 -1은 잡음으로 분류된 데이터
    -군집 수: len(set(labels)) - (1 if -1 in labels else 0)
    -곡선 형태 군집에도 적용할 수 있으나 군집별 밀도 차이와 변수 척도에 영향을 받음

7장 군집모형 성능평가
    -정답 레이블이 있으면 실제 묶음과 군집 결과의 일치 정도를 비교
    -adjusted_rand_score: 우연에 의한 일치를 보정한 데이터 쌍의 군집 일치도
    -mutual_info_score: 두 레이블 분할이 공유하는 정보량
    -normalized_mutual_info_score: 상호정보량을 정규화한 점수
    -homogeneity: 한 군집에 같은 정답 범주가 모이는 정도
    -completeness: 같은 정답 범주가 한 군집에 모이는 정도
    -v_measure: 동질성과 완전성의 조화평균
    -위 지표는 군집 번호를 정답 번호와 강제로 같게 바꾸지 않아도 비교 가능
    -silhouette_score(X, labels): 정답 없이 군집 내부의 응집도와 다른 군집과의 분리도 평가
    -실루엣은 -1~1이며 높을수록 더 잘 분리된 구조를 의미
    -여러 n_clusters의 실루엣을 비교하되 데이터 형태와 분석 목적도 함께 고려

8장 분류 데이터와 주요 모델
    -load 계열은 제공 데이터셋 불러오기, fetch 계열은 외부 데이터 내려받기, make 계열은 가상 데이터 생성
    -MNIST는 0~9 손글씨 숫자 이미지, load_digits 예제는 8×8 숫자 이미지 데이터
    -make_classification()의 n_samples는 행 수, n_features는 입력 변수 수
    -n_informative는 유용한 특징 수, n_redundant는 유용한 특징의 선형결합으로 만든 중복 특징 수
    -QDA: 클래스별 정규분포와 공분산을 추정해 분류
    -MultinomialNB: 나이브 베이즈 모형. 소스는 Iris에 적용하는 호출 예제를 제공
    -LogisticRegression: 클래스 확률을 계산하는 분류 모델이며 이진·다중 분류에 활용
    -DecisionTreeClassifier: 조건을 순차적으로 분기. max_depth로 깊이를 제한
    -Perceptron: 선형 경계를 학습하는 분류 모델
    -SVC: 마진과 커널을 이용한 분류. C·gamma가 경계의 복잡도 등에 영향
    -MLPClassifier: hidden_layer_sizes로 은닉층 구조를 지정하는 다층 신경망
    -predict(): 클래스 / predict_proba(): 클래스별 확률 / decision_function(): 판별 점수
    -확률 열의 클래스 순서는 model.classes_로 확인
    -단일 특징의 여러 샘플은 reshape(-1, 1), 한 샘플의 여러 특징은 reshape(1, -1)로 준비

9장 혼동행렬과 ROC-AUC
    -TP: 양성을 양성으로 예측 / TN: 음성을 음성으로 예측
    -FP: 음성을 양성으로 예측 / FN: 양성을 음성으로 예측
    -정확도 = (TP + TN) / 전체 수
    -정밀도 = TP / (TP + FP): 양성 예측 중 맞은 비율
    -재현율 = TP / (TP + FN): 실제 양성 중 찾아낸 비율
    -특이도 = TN / (TN + FP), 위양성률 = 1 - 특이도
    -F1은 정밀도·재현율의 조화평균
    -F-beta에서 beta > 1은 재현율, beta < 1은 정밀도를 더 중시
    -다중분류 macro는 클래스별 단순 평균, weighted는 클래스별 표본 수를 반영한 평균
    -ROC는 기준값 변화에 따른 위양성률(FPR)과 재현율(TPR)을 그린 곡선
    -roc_curve()에는 양성 확률 또는 decision_function()의 연속 점수를 사용
    -AUC는 ROC 아래 면적으로, 하나의 기준값에서 만든 혼동행렬과 다른 관점의 평가
    -불균형 데이터는 정확도만 보지 말고 소수 클래스의 정밀도·재현율·F1도 확인

10장 변수 선택과 PCA
    -변수 선택은 기존 특징 중 일부를 고르고, 차원 축소는 새로운 축으로 특징을 압축
    -PCA는 변수의 선형결합으로 분산을 많이 보존하는 주성분을 생성
    -PCA(n_components=2): 예제에서 Iris의 4개 특징을 2개 주성분으로 변환
    -explained_variance_ratio_: 주성분별 설명 분산 비율
    -components_: 원래 특징이 각 주성분에 기여하는 계수
    -PCA 변환은 원래 특징에서 학습 평균을 뺀 값을 기준으로 계산
    -상관 히트맵으로 특징 간 관계를 탐색
    -트리 계열의 feature_importances_로 모델이 활용한 특징 중요도 확인
    -특징 중요도는 인과관계를 증명하는 값은 아님
    -RFE: 중요도가 낮은 특징을 반복 제거해 지정한 수만 남김
    -SelectKBest(f_classif, k=...): 점수가 높은 K개 특징 선택

11장 하이퍼파라미터 탐색
    -하이퍼파라미터는 학습 전에 정하는 설정값이며 검증 성능을 기준으로 비교
    -validation_curve(): 한 설정값의 후보별 학습·교차검증 점수 계산
    -예제는 SVC의 gamma를 바꾸며 평균 점수와 표준편차를 시각화
    -학습 점수만 높고 검증 점수가 낮으면 과적합 가능성 확인
    -GridSearchCV(): 여러 설정 조합을 교차검증해 비교
    -Pipeline([('select', ...), ('svc', ...)]): 변수 선택과 모델을 한 흐름으로 연결
    -select__k, svc__C, svc__gamma처럼 단계명__매개변수명으로 탐색 범위 지정
    -best_params_: 선택된 설정 / best_estimator_: 선택된 모델
    -교차검증으로 설정을 고른 뒤 최종 성능은 별도로 남겨둔 테스트 데이터에서 평가
    -전처리·변수 선택도 각 학습 폴드 안에서 학습되도록 Pipeline에 포함

12장 자료 불균형 처리
    -소수 클래스가 적으면 다수 클래스만 잘 맞혀도 정확도가 높게 나타날 수 있음
    -train_test_split(..., stratify=y)로 분리 후 학습 데이터만 보정
    -SMOTE.fit_resample(): 소수 클래스의 이웃 관계를 이용해 합성 샘플 생성
    -테스트 데이터는 원래 분포를 유지하고 SMOTE를 적용하지 않음
    -class_weight는 특정 클래스의 오분류에 더 큰 비중을 주는 방식
    -소스는 RandomForest의 원본 학습·SMOTE 적용·가중치 적용 결과를 비교
    -classification_report()로 클래스별 precision·recall·F1과 표본 수 확인
    -보정 방법을 적용했다고 성능이 반드시 좋아지는 것은 아니므로 실제 지표로 비교

13장 앙상블과 모형 비교
    -앙상블은 여러 모델의 예측을 결합하는 방법
    -Bagging: 복원추출한 데이터로 여러 모델을 학습한 뒤 결과 결합
    -BaggingClassifier의 n_estimators는 모델 수, bootstrap=True는 복원추출 사용
    -oob_score_: 각 모델 학습에 뽑히지 않은 표본으로 계산한 평가 점수
    -RandomForest는 여러 결정나무와 특징 무작위 선택을 활용하는 앙상블
    -Boosting은 앞선 모델의 오차를 보완하도록 모델을 순차적으로 추가
    -예제는 AdaBoost·XGBoost·LightGBM·CatBoost를 비교
    -VotingClassifier(voting='hard'): 예측 클래스의 다수결
    -voting='soft': 클래스별 예측 확률을 평균해 결정
    -소프트 투표에는 확률 예측을 지원하는 모델이 필요하며 소스는 SVC(probability=True) 사용
    -model_measure() 함수로 같은 데이터의 정확도·정밀도·재현율·F1을 비교

14장 주요 용어와 소스 주의점
    -proba는 probability(확률)의 줄임말. 클래스 하나를 반환하는 predict()와 구분
    -np.linspace(시작, 끝, 개수)는 구간을 균등하게 나눈 수열 생성
    -cluster는 발견한 그룹, class는 분류할 범주, classifier는 분류 모델
    -계층적 군집의 linkage(iris, ...)에는 인코딩한 species 정답 열이 포함되어 있음
    -군집 학습은 꽃 측정값만 사용하고 species는 비교·평가에만 사용하도록 분리 필요
