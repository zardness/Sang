# 추론 원장

레퍼런스 화면 6장만으로는 알 수 없어서 **추론해 구현한 서버 로직** 목록입니다. 화면에서 직접 읽은 값은 [관찰], 이 문서의 항목은 [추론]입니다.

추론한 로직은 세 곳에서 확인할 수 있습니다.

- 코드 주석: `[추론 INF-xxx · 확신도]` (`grep -rn "추론 INF-" server src`)
- API 응답 헤더: `X-Rea-Inferred: INF-003,INF-004`
- 개발 모드 화면 하단의 "이 화면의 추론된 로직 n개" 배지, 그리고 화면 곳곳의 점선 `추론 INF-xxx` 태그

| ID | 영역 | 추론 내용 | 근거 (레퍼런스 화면) | 확신도 | 대안 가설 |
| --- | --- | --- | --- | --- | --- |
| INF-001 | 시세 데이터 | 시세는 실제 시장 데이터가 아니라 기준값(화면에 보인 종가·등락률)에 맞춘 가상 시계열이다. 시드 고정 기하 브라운 운동으로 생성하고 마지막 두 점을 화면 값에 고정한다. | 푸터 '수치는 예시 데이터입니다', 종목명 '가상 예시 종목'(화면 01, 03) | 높음 | 실제 시세 API를 지연 호출하는 구조 |
| INF-002 | 대시보드 헤드라인 | 헤드라인은 코스피와 코스닥 등락률 차이로 정한다. 코스피가 0.3%p 이상 앞서면 '대형주가 시장을 끌어올렸어요'. | 코스피 +1.16% > 코스닥 +0.54% 인 날의 문구(화면 02) | 중간 | LLM이 뉴스 요약으로 매일 작성 |
| INF-003 | 가격 예측 | '6개월 예측' 밴드는 5년 일간 로그수익률의 평균·표준편차로 만든 로그정규 분위수(10%~90%)이다. 화면의 'LSTM' 라벨은 원본이 신경망을 쓴다는 뜻으로 보이지만, 여기서는 설명 가능한 통계 모델로 대체했고 화면에도 그렇게 표시한다. | 점선 중앙값 + 시간이 갈수록 넓어지는 부채꼴 밴드(화면 03). 폭이 √t 에 비례해 보임 | 중간 | LSTM 다중 샘플의 분위수, 몬테카를로 부트스트랩 |
| INF-004 | Agent 분석 | Agent 요약과 비용·분산·변동성 등급은 규칙 기반이다. 비용: 총보수 <0.2% 낮음, <0.5% 중간. 분산: 구성 종목 ≥100 높음, ≥30 중간. 변동성: 연환산 변동성 <12% 낮음, <22% 중간. | 총보수 0.07% → 비용 낮음, S&P 500 → 분산 높음, 지수 ETF → 변동성 중간(화면 03) | 중간 | LLM이 지표를 읽고 등급을 매김 |
| INF-005 | AI 질문(RAG) | 답변 근거 점수는 질문과 문서의 코사인 유사도이며, 한국어 문자 2-gram TF-IDF로 계산한다. 답변은 상위 문서에서 질문과 가장 닮은 문장을 골라 구성한다. | '숫자는 질문과 문서의 유사도입니다. RAG 검색 결과를 그대로 보여줍니다'와 0~1 사이 점수(화면 06) | 중간 | 임베딩 벡터 검색 + LLM 생성 |
| INF-006 | 보고서 평가 | 100점은 근거 자료·용어 정확성·데이터 분석·위험 설명·기대 결과 5개 항목 × 20점이다. 각 항목은 문장 단위 신호(숫자·출처 표현, 용어 사전 단어, 비교 표현, 위험 단어, 결론 표현)를 세어 점수를 매기고, 가장 낮은 항목을 '꼭 수정'으로 띄운다. | 항목 점수 합 18+17+16+11+20=82, 최댓값 20(화면 05) | 높음 | LLM 채점 + 루브릭 |
| INF-007 | 보고서 수정 제안 | 위험 설명 수정 제안은 해당 ETF의 5년 최대 낙폭과 환율 위험을 숫자로 채운 템플릿 문장이다. | '과거 5년 최대 하락폭은 −24%였고, 원화 강세 시 환차손이 생길 수 있다'(화면 05) | 중간 | LLM이 문장을 다시 씀 |
| INF-008 | 총보수 계산 | '0.07%와 0.25%의 차이는 1,000만원을 10년 두면 약 33만원' 은 연 6.5% 수익을 가정한 복리 계산이다. | 1,000만 × 1.065¹⁰ × (0.9993¹⁰ − 0.9975¹⁰) ≈ 33.3만원(화면 04) | 중간 | 다른 수익률 가정(6~7%) |
| INF-009 | 학습 진행률 | '오늘 6분만 더 읽으면' 은 현재 장의 예상 읽기 시간에서 이미 읽은 시간을 뺀 값이다. 장 완료는 본문 끝까지 스크롤하거나 '다 읽었어요'를 누를 때 기록한다. | 3장 읽는 시간 6분 + 사이드바 'ETF 입문 3/7 · 6분'(화면 02, 04) | 중간 | 남은 장 전체 시간 합 |
| INF-010 | 레이아웃 | AI 패널을 열면 화면 폭이 1600px 미만일 때 왼쪽 메뉴를 아이콘 모드로 접는다. | AI 패널이 열린 화면(03, 06)은 모두 메뉴가 접혀 있음 | 낮음 | 페이지별로 고정된 메뉴 상태 |

| INF-012 | Agent 연동 | P02·P04 Agent 결과는 앱이 다시 계산하지 않고, Agent가 저장한 가장 최근 실행 폴더(p02_out·p04_out/<시각>/<종목>)의 result.json·페르소나 보고서를 읽어 그대로 보여 준다. 사업부 분기표는 주장 문장(axis·businessId·horizon)의 숫자를 모아 다시 짠다. 폴더가 설정되지 않으면 노트북 출력에서 뽑은 스냅샷을 쓴다. | 노트북 [11-1]·[13-1] 저장 파일 목록, PC result.json 최상위 키, 보고서의 SUMMARY·LOCKED 구역 표시 | 중간 | Agent를 Python 서버로 상시 띄우고 API로 호출 |
